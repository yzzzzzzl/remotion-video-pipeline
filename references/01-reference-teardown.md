# 阶段 1（模式 A）：参考视频拆解

> **先路由**：给了视频链接 / 本地原片 → 走本文（模式 A）。**只给主题、文章、要点或素材名，没有可逐帧拆的原片 → 走 `11-topic-only.md`（模式 B 推导）**，跳过下面 1.1~1.3，用默认值直接产出同一张配方卡。两条路汇合到配方卡后，阶段 2~7 完全一致。

目标不是「看懂它在讲什么」，而是产出一张**配方卡**：视觉体系、叙事结构、节奏数据。拆完要能一句话说清「这条片子为什么好看」。

## 1.1 拿到片子

### 抖音（`v.douyin.com` 短链 / `douyin.com/video/<id>`）

`yt-dlp` 直接下会要求 cookies（`--cookies-from-browser` 也常失败）。可行路线是**无头 Chrome + CDP 截获媒体流**：

```bash
# 1) 短链解析出视频 ID
curl -sL -A "<iPhone UA>" "https://v.douyin.com/XXXX/" -o page.html -w "%{url_effective}\n"

# 2) 无头浏览器打开视频页，抓 media-video-avc1 / media-audio-und-mp4a 流地址
node scripts/capture_douyin.js "https://www.douyin.com/video/<id>" urls.json

# 3) 流地址有时效（几十分钟），立刻下载并合并
curl -A "<桌面 UA>" -H "Referer: https://www.douyin.com/" "<video_url>" -o video.mp4
curl -A "<桌面 UA>" -H "Referer: https://www.douyin.com/" "<audio_url>" -o audio.mp4
ffmpeg -y -i video.mp4 -i audio.mp4 -c copy original.mp4
```

要点：
- 必须加 `--disable-blink-features=AutomationControlled` + 桌面 UA，否则页面不开播
- 页面通常不自动播放，脚本里要 `document.querySelector('video')?.play()` 并等 8~10 秒
- 得到的常是**分片流**：视频流和音频流分开，必须 ffmpeg 合并，否则没声音
- 分享页 HTML 里只有元数据（标题/作者/封面），**没有直链**，别浪费时间扒 DOM

### 其他平台

能拿到本地文件最好（用户直接给 MP4）。B 站/YouTube 优先 `yt-dlp`；微博/小红书参照抖音思路走 CDP。

## 1.2 抽帧看视觉

```bash
ffmpeg -y -i original.mp4 -vf "fps=1/10,scale=640:-1" -q:v 3 frames/frame_%03d.jpg
```

10 秒一帧足够；镜头切换密集的片子用 `fps=1/3`。然后用视觉检查逐帧读：**版式、配色、字幕样式、动效进场方式、是否有真人小窗、有没有章节标签/进度条/计数器**。

读帧时问三个问题：① 主体元素在画面哪个区域？② 一屏几个文字块？③ 哪些元素是「逐个进场」的？

**开场单独加密抽帧**：前 15 秒用 `fps=1`（1 秒一帧）单独抽一遍，统计镜头切点数、首屏 Hook 类型、常驻装饰层，写进配方卡。10 秒一帧会把整段开场直接漏掉，而开场恰恰是最该拆的地方（见 `10-first-15s.md`）。

## 1.3 转写拿结构

音频抽出来转写（`AudioTranscribe`，或本地 `faster-whisper`）：

```bash
ffmpeg -y -i original.mp4 -vn -ac 1 -ar 16000 -b:a 64k audio.mp3
```

**注意**：长音频在线转写可能超时；13 分钟以上的建议直接走本地 whisper（见 `03-audio-timeline.md` 的环境配置）。

拿到带时间戳的转写后，统计：
- 总时长、段落切换点（转写稿里的空档 ≈ 章节边界）
- 每章时长占比 → 决定自己片子的章节配额
- 口播语速（字数 / 分钟）→ 决定自己稿子该写多少字

## 1.4 配方卡模板

写成这张卡（放 `analysis/配方卡.md`）：模式 A 拆完填、模式 B 按 `11-topic-only.md` §2 推导填，**字段一致、不许留「待定」**，后续所有决策以它为准：

```markdown
## 配方卡来源
- 模式：A 拆解 / B 推导
- 输入：原片路径 / 主题 + 用户指定覆盖项

## 视觉
- 画幅/分辨率/帧率：
- 底色/主色/强调色（取色值）：
- 主题画风（技术 / 书籍 / 财经 / 科普 / 极简）：__ → 开场母题见 `10-first-15s.md` §5
- 版式：主体区（y 范围）+ 常驻元素（位置）
- 字幕：字号/行数/是否有底色/是否逐字进场
- 装饰：章节标签 / 进度条 / 帧计数器 / 真人小窗 / 其他

## 结构
| 章节 | 时长 | 作用 | 我方对应章节 |
|---|---|---|---|
| 开场 Hook | 0:00-0:30 | 否定误区 | ... |

## 节奏
- 单页最长停留：__ 秒
- 开场 15 秒：切点数 __ / 首屏 Hook 类型 __ / 常驻装饰层 __（见 `10-first-15s.md`）
- 是否有「总览页复用」：是/否，复用次数
- 转场方式：硬切/淡入/位移

## 可迁移 / 不可迁移
- 可迁移（结构、节奏、视觉语法）：
- 不可迁移（真人出镜、特定素材、作者个人梗）：
```

## 1.5 边界

- 只拆**结构和方法**，台词必须原创重写（同题材、同结构、不同措辞与例子），不要逐句改写原文
- 作者的个人梗/水印/片头片尾不要复用
- 拆完把配方卡交付给用户看（**软门**：只给看、不停机等回复，用户有异议再改）。整条流水线只有 G1 / G2 两道必须停顿的确认门，见 `09-interaction-gates.md`
