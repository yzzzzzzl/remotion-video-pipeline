# 阶段 4↔5：外部素材检索、下载与落地

> **触发**：分镜设计时发现某些镜头页用真实素材能明显提升可信度 / 质感 / 信息密度——实拍空镜、产品/书籍封面、地图/界面截图、场景氛围图、特定图标、纹理背景、短片段音效。**准入从「没有它就假」放宽到「有它更好」**，但三关否决照旧（§0）。
> **做什么**：由 agent 主动上网检索可商用素材 → 筛选下载 → 统一画风 → 落地到工程 `public/` → 在镜头组件里用 `staticFile()` 引用。
> **不是第三道门**：素材清单随配方卡一起给用户看（软门），**不等回复、不新增确认**；整条流水线仍只有 G1 / G2 两次打断（`09`）。

---

## 0. 什么时候该找素材，什么时候继续用代码

**默认倾向：贴题、可商用、能统一画风的素材优先，代码兜底。** 真实素材在可信度与质感上天然强于代码 mockup，短视频观众对「像真的」很敏感；代价是版权与画风处理量上升，用 §4 / §5 消化，不靠降低判据回避。

### 三档判据（逐页过，A / B 都进素材清单）

| 档 | 判据 | 处理 |
|---|---|---|
| **A 必用** | 没有它画面就假：真实存在的具体物件、实拍质感是关键、操作录屏 | 优先找素材；找不到就调整镜头角度或台词，**不要硬用代码假扮真物件** |
| **B 优先用**（本次放宽的重点） | 有它明显更好：贴题实拍（场景/氛围/物件特写）、现成图标字体、纹理背景、数据/产品界面截图、短音效 | **默认找素材**；只有检索不到能过三关的，才退回代码 |
| **C 仍用代码** | 代码更清晰或素材帮不上忙：抽象概念、流程关系、卡片列表数字时间轴代码块、章节标签字幕条进度条、声波头像、纯色渐变 | 直接用代码，不浪费检索成本 |

一句话判据：**「有它更好」就找——只要过得了版权、画风、元素化三关；代码只在素材帮不上忙或过不了关时兜底。**

### 三关否决（放宽后更要盯，任一不过就退回代码）

| 关 | 否决条件 |
|---|---|
| 版权关 | 授权不明 / 商用受限 / 无法按要求署名（§4） |
| 画风关 | 裁色调色后仍与主题 token 明显冲突、无法纳入同一套色板（§5） |
| 元素关 | **只有整页铺满才好看**，作为元素进场就失去意义——直接退回代码（§7） |

> 元素关是放宽后最容易踩的一条。素材变多不等于可以把流程页换成网图：一屏仍只放关键词，素材是元素不是背景，否则既违反铁律一又丢掉信息密度。

## 2. 素材清单（写进 `analysis/配方卡.md` 的新增小节）

清单是这一阶段的唯一新产物，格式固定，逐项不留空：

```markdown
## 素材清单
| # | 用于哪页（章节/台词行） | 类型 | 需求描述 | 来源 | 授权 | 落地文件 |
|---|---|---|---|---|---|---|
| 1 | ch2 / 行6「真实操作界面」 | 录屏 | 某软件导出流程，10~15s | 用户录屏 / 自录 | 自有 | public/assets/export-demo.mp4 |
| 2 | ch1 / 行2「书籍封面」 | 图片 | 《资本论》封面，竖版 ≥1080 | Openverse | CC BY | public/assets/capital-cover.jpg |
| 3 | 开场 / 行1 冲击点 | 音效 | 低频 whoosh，<2s | Pixabay | Pixabay 内容许可 | public/assets/whoosh.mp3 |
```

字段说明：

- **用于哪页**：精确到章节号 + 台词行索引，和 `04` 的 `ShotDef.from` 对得上；找不到对应台词的素材不要下。
- **类型**：图片 / 视频 / 录屏 / 图标 / 音效 / 字体。
- **需求描述**：写清主体、朝向、时长、最低分辨率——检索时按这个筛，别看到顺眼就下。
- **来源 / 授权 / 落地文件**：**不允许留空**。`授权` 一栏是后面版权自检的唯一依据（§4）。

## 3. 检索渠道与优先级

按「版权清晰度 × 贴题度」排序，从上往下找，够用就停：

| 优先级 | 渠道 | 适合 | 授权特点 | 检索 / 下载方式 |
|---|---|---|---|---|
| 1 | **用户自有素材** | 任何 | 用户自己负责 | 直接问用户要，或读 `source/` |
| 2 | **自录 / 自拍 / 录屏** | 操作过程、真人小窗 | 自有 | ffmpeg 录屏 / 手机拍，落 `source/` |
| 3 | **Wikimedia Commons** | 书籍封面、历史图、地理实景 | CC / 公有领域为主，逐条看 | `openverse` / Commons 搜索页，注意署名要求 |
| 4 | **Openverse**（openverse.org） | 通用图片，CC 聚合搜索 | 按 CC 类型逐条筛 | 搜到条目后跳原站下载，记下 license |
| 5 | **Unsplash / Pexels / Pixabay** | 高质量实拍、纹理、空镜 | 各自的内容许可，通常可商用免署名 | 直接抓图片页；音频走 Pixabay |
| 6 | **图标库**（Lucide / Tabler / Heroicons） | 线性图标 | 开源许可 | 下 SVG 或直接用组件包 |

**检索工具**：用联网搜索找具体条目 → 打开条目页确认授权 → 下载原图/原文件。**不要把搜索结果缩略图当素材**（带水印、分辨率低、授权不明）。

**下载落点统一走 F 盘**（用户隔离规则）：素材直接下到工作区工程的 `public/assets/`，别先下到 Downloads 再搬。临时文件用 `F:\dev-env\tmp`。

## 4. 版权判定（必过，不可跳过）

按下表逐条判定，**任何一条不满足就换素材，不要「先用着再说」**：

| 检查 | 判据 | 不过就 |
|---|---|---|
| 授权类型 | 公有领域 / CC0 / CC BY / 平台内容许可 —— 逐条看条目页 | 换源；CC BY 必须在成片或工程里署名 |
| 可商用 | 条目页明确允许商用 | 换源，尤其是「仅个人使用」的图 |
| 人脸 / 商标 / 作品 | 出现可识别人脸、品牌 logo、受版权保护的作品封面 | 换源，或确认属于合理使用/公有领域 |
| 署名要求 | CC BY 类必须在 `analysis/配方卡.md` 的素材清单注明作者 + 链接 + 协议 | 补署名，否则删掉换 CC0 |
| 来源可追溯 | 清单里的来源 URL 能打开、能对上文件 | 补 URL，别留「网上找的」 |

**红线**：
- 不下载带水印的图当素材，也不自己去水印后用（去除水印本身即侵权）。
- 不把别人的完整视频片段剪进成片当内容（参考片只拆结构，不搬运画面——SKILL.md「纯搬运」禁令）。
- 不确定授权时，**用代码画一个近似示意**替代，这是这套流程的兜底优势。

## 5. 统一画风预处理（最容易翻车的一步）

外部素材的默认风格几乎一定和主题画风（`10` §5 的映射表 + `05` 的 `C` token）对不上。**不处理直接用 = 视觉割裂，验收会被打回。** 逐项处理后再落地：

| 问题 | 处理 | 命令 / 代码 |
|---|---|---|
| 色彩和主题色板冲突 | 降饱和 + 往主题底色压一层 | `<Img style={{filter:'saturate(.7) contrast(1.08)'}}/>` 或 ffmpeg `eq=saturation=0.7` |
| 背景太杂抢字幕 | 去背转透明 PNG，或裁主体 | `rembg` / ffmpeg `chromakey` |
| 亮度不一致，切章闪一下 | 统一亮度/对比度到同一档 | ffmpeg `eq=brightness=-0.04:contrast=1.1` |
| 分辨率过大拖慢渲染 | 长边预缩到 1.5× 画幅宽以内 | 横屏 `ffmpeg -vf scale='min(2880,iw)':-2`；竖屏覆盖时 `min(1620,iw)` |
| 格式 webp / avif 兼容问题 | 转 PNG（带透明）或 JPG | `ffmpeg -i in.webp out.png` |
| 实拍太「真」和动画不融 | 叠一层主题色半透明蒙版 + 细描边 | 组件里盖 `background:C.bgDeep; opacity:.12` 的 div |

**尺寸基准（默认横屏）**：1920×1080 主体内容区约 1560×740（y 130~870），素材长边 ≥1920；用户明确要竖屏覆盖时，主体 1080×1030（y 420~1450）、长边 ≥1080。低于这个会糊。

**处理原则**：宁可把素材处理得「有点风格化」，也别让它以原始面貌直接混进动画——观众对风格断裂非常敏感，对「稍微调过色」无感。

## 6. 落地与引用（Remotion 工程约定）

### 目录

```
remotion-project/
├── public/
│   ├── voiceover.mp3          # 已有：音轨
│   └── assets/                # 新增：外部素材统一放这里
│       ├── capital-cover.jpg
│       ├── export-demo.mp4
│       └── whoosh.mp3
├── analysis/配方卡.md          # 素材清单 + 来源登记
└── src/
    └── scenes/Scenes.tsx      # 镜头组件引用素材
```

命名：`小写英文-短横线.扩展名`，不用中文/空格——避免路径转义和跨平台问题。

### 引用代码

Remotion 的 `public/` 是静态资源根，用 `staticFile()` 引用（不是相对路径）：

```tsx
import { Img, OffthreadVideo, Audio, staticFile } from 'remotion';

// 图片：作为元素进场，不是整页背景
<Img
  src={staticFile('assets/capital-cover.jpg')}
  style={{ width: 420, borderRadius: 12, filter: 'saturate(.7)' }}
/>

// 视频片段 / 录屏：必须带 muted，音轨统一由 voiceover.mp3 承担
<OffthreadVideo
  src={staticFile('assets/export-demo.mp4')}
  muted
  style={{ width: 720, borderRadius: 12 }}
/>

// 音效：短片段，单独挂，体积压到最小
<Audio src={staticFile('assets/whoosh.mp3')} volume={0.35} />
```

**为什么用 `OffthreadVideo` 而不是 `<Video>`**：解码在独立线程，渲染时不易掉帧/卡死（`07-gotchas.md` 的渲染 crash 坑）。

**音轨纪律**：`voiceover.mp3` 仍是**唯一主音轨**，素材音效只是点缀、音量压到 0.2~0.4，且必须挂到台词锚点上，不能全程铺——否则会盖住口播、破坏 G2 试听基准。

## 7. 素材进场也要守四条铁律（`08-screen-rules.md`）

外部素材不是「贴上去就行」，它同样接受画面四条验收：

| 铁律 | 对素材的具体要求 |
|---|---|
| ① 禁止整页出现 | 素材只是元素，和标题/卡片错峰进场；**禁止把网图铺满主体区当背景**——这是最常见的违规 |
| ② 只放关键词 | 素材上不要叠大段文字；说明文字放字幕条，素材旁最多一行关键词 |
| ③ 音画同步靠查字幕 | 素材的进场时刻用 `at(i)` 从 `timeline.json` 换算，**禁止拍常数**；抽两帧验「发声后 2 帧在进场、发声前 5 帧没出现」 |
| ④ 静态不能撑场 | 静态图停留 >3s 必须挂运动：缓推近 1.0→1.06、缓平移、遮罩揭示；**录屏片段优先于静态截图 + 花字** |

另外两条来自别的文档，一并守：

- **画风一致**（`10` §5）：开场 15 秒若用素材，必须和正片同一套色板/滤镜；HUD 在 frame 450 后消失。
- **单页时长**（`04`）：含素材的页也遵守 4~15s，超 20s 就拆页，不能因为素材好看就延长。

## 8. 常见坑

| 症状 | 病因 |
|---|---|
| 下载了但渲染报 404 | 文件没落 `public/` 或路径拼错；`staticFile()` 的参数要相对 `public/`，不含 `public/` 前缀 |
| 画面风格割裂，像拼贴 | 跳过 §5 预处理，直接用了原始网图 |
| 一整页就是一张网图，被判 PPT 味 | 违反铁律一，把素材当背景铺了；改成元素 + 错峰进场 |
| 素材停几秒不动，观感卡住 | 违反铁律四，静态图没挂运动；换成缓推近或录屏 |
| 素材比口播早/晚出现 | 进场时刻拍了常数；改用 `at(i)` 从 timeline 换算 |
| 渲染中途卡死 / 掉帧 | 用了 `<Video>` 或素材分辨率过大；换 `OffthreadVideo` + 预缩放 |
| 音轨被素材音效盖住 | 音效音量过大或全程铺；压到 0.2~0.4 并挂台词锚点 |
| 被指出用了有版权的图 | 清单里 `授权` 栏留空或来源不明；回到 §4 换源并补署名 |
| 素材下到了 Downloads / C 盘 | 违反 F 盘隔离规则；直接下到工程 `public/assets/` |

## 10. 反模式

- 先囤素材再写分镜——必然退化成「一页一图」。
- 用搜索缩略图当素材——低清、带水印、授权不明。
- 下载带水印的图再去水印使用——侵权。
- 把网图铺满主体区当背景——违反铁律一。
- 静态图停 3 秒以上不动——违反铁律四。
- 素材进场时刻拍常数而非查字幕——违反铁律三。
- 用 `<Video>` 放大分辨率原片——渲染掉帧，换 `OffthreadVideo` + 预缩放。
- 音效全程铺满、盖住口播——破坏 G2 的试听基准。
- 因为用了外部素材就新增一道确认门——不，仍然只有 G1 / G2。
- 把参考视频的画面剪进成片——那是搬运，不是素材。
