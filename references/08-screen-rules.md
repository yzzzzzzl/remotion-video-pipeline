# 画面四条铁律

这四条来自一条 13 分钟教程片的逐帧拆解 + 一轮完整返工。守不住任何一条，成片立刻掉进「PPT 味」。每条给三样东西：**判据**（怎么算违反）、**实现**（代码层面怎么做）、**自检**（渲染前怎么验证）。

优先级：**不整页出现 > 只放关键词 > 查字幕锚点 > 加运动**。信息超载时的唯一解法是拆页，不是压缩字号或堆更多元素。

> **开场（第 0 章）四条更严**：静止上限从 3s 收到 **1.5s**、主体文字从 ≤5 收到 **≤3 块**、第 3 帧必须是半成品、每页至少 1 个永动元素。另有主干铁律第 8 条（≥6 页快切、画风一致、HUD 不残留），全套判据见 `10-first-15s.md`。

---

## 铁律一：禁止整页出现

**为什么**：场景切进来就把内容铺满，观众一眼读完，接下来 20 秒没有任何信息增量——节奏当场死掉。

**规则**
- 进场单位是**元素**，不是页面。一行标题、一个数字、一个图标、一张卡片、一段连线，各自有自己的进场时刻。
- 进场顺序 = **语义顺序**，由口播决定，不由版式美观决定。口播说到哪个内容，哪个元素才出现。
- 「总览页列出全部要点」也不例外：要点是逐个进场的，只是间隔短一些（8~12 帧）。

**实现**

```tsx
// Chrome.tsx 提供 popIn(local, delay) -> { opacity, translateY }
// delay 用「本页内帧号」，按语义顺序递增
<Card style={popIn(local, at(1) + 4)}>① 提示词不用你写</Card>
<Card style={popIn(local, at(1) + 16)}>② 给参考比给文字管用</Card>
```

`at(i)` 来自 `ShotEngine`：返回本章第 i 句台词在本页内的帧偏移（见铁律三）。没有台词可锚时，按 8~12 帧等差递增，别一次性全出。

**自检**：切入后第 3 帧截图，画面应当看起来是「半成品」——只有一两个元素在场上。如果第 3 帧就是完整版式，违规。

## 铁律二：屏幕上只放关键词

**为什么**：不加约束，AI 会把逐字稿整段搬上屏。配音在念这句话、画面上也写着这句话，观众等于在看你念稿，而不是看视频。

**规则**
- 主画面只放：**关键词、短语、数字、短标签**。完整句子只出现在底部字幕条。
- 一屏文字元素 **≤ 5 个**（含页面标题）；单个元素 **≤ 12 字**。
- 整页最多出现一句「金句」，且它必须是收束页（章节结论/结尾），不能是解释页。
- 画面的丰富度靠**动画**，不靠加字。

**抽象逻辑用图形演，别用文字解释**

| 想表达 | 不要写 | 要做 |
|---|---|---|
| 流程 A→B→C | 三行文字说明步骤 | 连线从 A 生长到 B，再生长到 C，节点逐个点亮 |
| 数据积累 | “会不断沉淀资产” | 方块从底部堆叠升起，数量递增 |
| 筛选/过滤 | “只保留符合条件的内容” | 元素从上方流下，穿过筛选框，被挡住的落灰 |
| 转化/映射 | “把需求转成提示词” | 一个元素从左侧飞到右侧，变形为另一个形状 |
| 对比 | “两者差别是…” | 左右两栏并置，一侧被红线划掉，另一侧放大 |
| 完成/确认 | “这样就完成了” | 卡片描边变绿 + 打勾 + 轻微弹跳 |

**自检**：把画面上所有文字按阅读顺序抄下来连成一段，如果读起来像口播稿 → 违规，砍到只剩关键词。

## 铁律三：音画同步的真正解法——查字幕，不估

**为什么**：音画不同步是被问得最多的问题。根因是「按句子顺序估算时长」或「平均分配」，越到后面偏得越多。

**规则**
- 动画什么时候出现，**按字幕里对应文字的时间点**来定。
- 流程是「去字幕文件里查这个词出现在第几秒」，而不是「这句话大概多长、我分三段」。
- 每个动画锚点必须能指名道姓地绑到某一句台词（或句中某个关键词）。

**数据链**（唯一允许的锚点来源）

```
关键词 → 行索引 i → timeline.lines[i].startFrame
       → 页内偏移 = startFrame - 本页起始帧
       → 组件里的 delay
```

`ShotEngine` 已经把这个换算封装成 `at(i)`：

```tsx
// 第 3 句台词说到时，元素才进场（+4 帧让字幕先出来一点）
const d = at(3) + 4;
<div style={popIn(local, d)}>…</div>
```

**反模式**：`interpolate(local, [30, 45], …)` 里的 30/45 是拍脑袋写的常数。除非该页只覆盖一句台词且已核对过，否则一律换成 `at(i)`。

**自检**（每次改稿必做）
1. 抽「该词发声帧 + 2」的静帧 → 元素应正在进场（半透明/位移中）
2. 抽「该词发声帧 − 5」的静帧 → 元素应还没出现
3. 两帧都对，才算同步；只对第 1 帧不够（元素可能早就铺好了）

## 铁律四：静态画面撑不了场

**为什么**：不露脸的视频尤其致命。一张静态截图停在那里超过几秒，节奏就垮了——观众会以为视频卡住。

**规则**
- 任何元素在页面上停留 **> 3 秒**，必须挂一个「活」的动效。
- 常用四种，成本从低到高：
  1. **缓推近**：`scale 1.0 → 1.06`，线性 6 秒循环，最省事、最有效
  2. **缓平移**：截图横向/纵向 `translate` 缓慢移动，模拟镜头扫过
  3. **打字机**：代码、prompt、配置逐字敲出，光标闪烁
  4. **遮罩揭示**：用渐变遮罩从左向右扫过，把静态图「演」成动态
- 讲操作过程**优先用录屏**，不要拿静态截图 + 花字冒充动画。
- 数字/结论类页面：数字滚动增长、卡片呼吸、光晕漂移（`Background` 已自带）。

**自检**：任取 3 秒窗口抽 3 帧（间隔 1.5 秒），三帧**完全相同** → 违规。有细微变化（1~2px 位移、1% 缩放）即通过。

## 渲染前逐页自检卡

每页过一遍，六道全绿才进全片渲染：

- [ ] 切入第 3 帧是半成品（元素逐个进场，不是整页铺好）
- [ ] 文字元素 ≤ 5 个，单个 ≤ 12 字，没有整句台词
- [ ] 每个进场锚点都能指到某句台词（`at(i)`，不是常数）
- [ ] 没有连续 3 秒完全静止的画面
- [ ] 抽象逻辑有对应示意动画，而不是用文字解释
- [ ] **（仅开场）** 前 15s ≥6 页、单页 ≤75 帧、首屏 ≤45 帧、frame 0 在动、无 1.5s 静止、HUD 在 frame 450 后无残留、色板与正片一致 → `10-first-15s.md` §7

> 六条里有任何一条不过，都别急着全片渲染——全片渲染是 6× 实时，改完再渲才是成本最低的路径。见 `06-qc-render.md`。
