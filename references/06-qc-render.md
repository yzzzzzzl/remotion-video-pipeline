# 阶段 6：抽帧质检、渲染与改稿

> **前置**：G2 试听确认已通过（`09-interaction-gates.md`）。没确认就渲染，改音频要连带返工 `timeline.json`、镜头表 `from`、画面文案四处，而全片渲染约 6× 实时。

## 质检：先静帧，后全片

全片渲染约 6× 实时（4 分钟片子渲 25 分钟），**盲渲是最大的浪费**。模式 B（只给主题）没有参考片可对照，验收全靠下面的自检卡与铁律，不靠「像不像某条片子」（`11-topic-only.md` §5）。流程：

1. 选抽检点：**frame 0 / 开场每页页首+中段+页尾 / frame 450（切章后一帧）** + 每章起始帧 + 每个镜头切换点（`lines[shot.from].startFrame + 10`）+ 结尾。开场抽检不少于 8 帧，硬指标见 `10-first-15s.md` §7
2. 批量出静帧：

```bash
./node_modules/.bin/remotion still Video out/qc_f150.png --frame=150
```

3. 用视觉检查逐帧看四个问题：画面与该句台词是否对应、有无文字溢出/重叠、元素是否按预期进场、字幕条文字是否正确
4. 同步专项（铁律三）：每个进场锚点抽两帧——「台词发声后 2 帧」应正在进场，「发声前 5 帧」应还没出现
5. 逐页过 `08-screen-rules.md` 的六道自检卡（半成品首帧 / ≤5 元素 / 锚点可指认 / 无 3 秒静止 / 抽象逻辑有示意 / 开场专项）；**开场另过 `10-first-15s.md` §7**（≥6 页、单页 ≤75 帧、frame 0 在动、无 1.5s 静止、画风一致、HUD 在 450 帧后无残留）
6. 改一处 → 只重渲**受影响区间**的静帧确认，再进全片

已知典型缺陷对照：

| 症状 | 病因 |
|---|---|
| 台词说到解释内容，画面还是总览页 | 镜头表 `from` 错位（通常差 1）；见 04 §常见 bug |
| 字幕比语音早/晚 | 对轴匹配率低或删行后没重对轴 |
| 文字贴边被裁 | 内容区侵入安全区；检查 `top` 值与元素总高 |
| 渲染中途 crash | 组件引用了 undefined 变量（如定义 `op` 用了 `opacity`）——某个帧才走到，静帧测不到，按 crash 帧号定位组件 |
| **前 8 秒画面一动不动 / 生硬** | 开场沿用正片 4~15 秒/页，没做帧级快切；见 `10-first-15s.md` |
| **切章后残留 HUD / 画面闪一下** | 开场常驻层没限制在第 0 章，或 `Video.tsx` 全局背景色没换成 `C.bgDeep` |
| **某页风格突然不像全片** | 外部素材跳过统一画风预处理（`12` §5），或直接用原始网图 |
| **素材页渲染 404 / 掉帧** | 路径没从 `public/` 起（`staticFile()` 参数不含前缀），或素材分辨率过大 / 用了 `<Video>`；见 `12` §6、§8 |
| **网图整页铺着不动** | 违反铁律一/四，素材被当背景；见 `12` §7 |

## 渲染

```bash
cd remotion-project
./node_modules/.bin/remotion render Video "<output>/<标题>-<版本后缀>.mp4" --codec=h264
```

- 后台运行 + 定期看进度（`Encoded N/M` 输出在 tail）；全片渲完才写文件，中途 `ls` 看不到是正常的
- 产出验证：

```bash
ffprobe -show_entries format=duration -show_entries stream=codec_type,width,height <mp4>
# duration 应等于 timeline.durationInFrames / fps（±0.1s）
```

- 版本命名：`<标题>.mp4` → `<标题>-真人配音版.mp4` → `<标题>-分镜增强版.mp4` → `<标题>-科技感开场版.mp4`……**每次改稿出新文件，不覆盖**，用户经常要回退

## 改稿速查（数据驱动的好处）

| 改什么 | 动哪里 | 重跑什么 |
|---|---|---|
| 某句台词 | `scenes.json` 该行 `t`（字数变化大则重拆行） | TTS/对轴 → **重走 G2** → 渲染 |
| 删连续几句 | 剪音轨（句末剪断+垫静音）→ timeline 删行、改章节 endFrame、durationInFrames → 镜头表 `from` 前移 → 删对应画面里的文案 | **重走 G2** → 仅渲染 |
| 用户重录配音 | 替换 `source/` 录音 | 路线 B 全流程 → **重走 G2** → 渲染 |
| 换 AI 音色 / 语速 | `--voice` / `--rate` | `make_audio.py` 重跑 + timeline 重算 → **重走 G2** → 渲染 |
| 换配色/字体 | `Chrome.tsx` 的 `C` / `FONT` + `Video.tsx` 全局背景色 | 仅渲染（音轨没变，不用重走 G2） |
| 调某页动画 | `Scenes.tsx` 该组件 | 仅渲染 |
| **重做开头 15 秒** | 新建/改 `scenes/Opening.tsx`，`Scenes.tsx` 把 `HookScene` 指向它 | **仅渲染**（音轨/时间轴零改动）；按 `10-first-15s.md` §7 重验 |
| 加/减章节 | scenes.json 章节与行 + 新 Scene 组件 + `SCENE_COMPONENTS` | 全链路（回到 G1） |

**删句三同步铁律**（漏一个就出 bug）：① 音轨剪到句末；② timeline.json 删行+总长；③ 镜头表/画面文案里该句的内容全部移除。改完全局 grep 被删台词关键词确认无残留。

**门的重算规则**：音轨变了（换配音、重录、增删句、调节奏）→ 重走 G2，把新音轨再交付试听；只动画面且音轨不变 → 不用。口播稿整篇重写 → 视同新项目，回到 G1。
