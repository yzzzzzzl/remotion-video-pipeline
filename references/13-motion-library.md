# 讲解型动效库：口播词触发的语义动作

> 阶段 4 分镜选动作、阶段 5 搭画面时查。补的是 `10-first-15s.md` §4 那张表没覆盖的部分——**开场装饰特效**（数字滚动、故障字、代码雨…）由 `10` 管，**正片「讲到什么就演什么」的语义动作**由本文件管。两者不冲突，同一页可叠加：语义动作是骨架，装饰特效是质感。
>
> 来源：从「启序AI-豆包口播导演工具箱」三期 40 条动效提示词提炼、转译而成（原片为竖屏真人口播 MG）。**不照搬**：本 skill 能力边界是「图文/图表/界面 mockup 级」（`SKILL.md`「什么时候不用」），真人出镜统一用声波头像 / 用户素材替代，历史成片秒数一律重新按 `timeline.json` 卡点。

## 0. 三条转译规则（用之前先读，避免把工具箱原样搬进来踩坑）

| 工具箱原说法 | 本 skill 的转译 | 原因 |
|---|---|---|
| 「用同一段真人原片 + 透明人像分层，人物挡在标题前」 | 真人层换成**用户素材（`12` 三档 A）或声波头像**；遮挡关系保留——大字分「后景层 / 前景层」，用一个前景元素（头像、卡片、图标）压住标题一角 | 我们没有同步抠像能力；硬做 = 边缘穿帮。有用户真人素材才启用，否则用元素遮挡表达同一语义 |
| 「X 秒听到某词时开始动」（历史成片秒数） | 一律 `at(i)` 从 `timeline.json` 换算本页帧，**禁用原文秒数** | 新一期稿子不同，秒数必然错；这是铁律三 |
| 「给动作配短提示音」 | 音效压 **0.2~0.4** 音量、挂同一台词锚点、不盖主音轨；素材走 `12` §6 | `voiceover.mp3` 是唯一主音轨，音效只能点缀 |
| 「在真实截图上拖高柱子 / 逐段连线」 | 优先**代码画可交互 mockup**（`08` 铁律四：静态截图顶不住 3 秒）；确需真实界面按 `12` 找录屏素材 | 静态截图 + 花字是明令反模式 |

**不用真人也能表达"遮挡"语义的替代**：后景大字 + 前景一个 `Card` / 声波头像 / 工具图标压住标题下缘 1/4，留出文字上半可辨识。观众读到的是「字在物后面」的空间感，不是必须看到人脸。

## 1. 动效模式总表（21 个）

按讲解目的分七组。选法：先定这一页**要让观众看懂什么**（`04` 分镜第 2 步），再按下表挑一个主动作；一页只挑一个主动作，其余用 `10` 的装饰特效补运动密度。

| 组 | 编号 · 模式名 | 一句话 | 时机信号（台词里的词） |
|---|---|---|---|
| **A 钩子** | M01 前后景大字遮挡 | 大字分前后层，前景元素压住一角 | 主题词、数字首次出现 |
| | M02 真实成果首帧 | 首帧直接铺本期真结果 + 一个问题 | 「一篇长文怎么变成…」 |
| | M03 数字重音上移 | 说到数字时大字短距上移停稳 | 「8 个」「59.2 万亿」「第 1」 |
| | M04 逐格点亮预告 | 刻度/占位格逐格亮，预告内容 | 列举前的「六个」「几个」 |
| **B 文字** | M05 重点词扫入 | 关键词用识别色从左扫出底色 | 当句重音词 |
| | M06 一笔引线 | 标题下引一笔连到主图/证据 | 章节名、工具名 |
| | M07 几何擦除换版 | 几何擦除把底图换成新标题 | 日期、转折、「其实」 |
| **C 过程** | M08 双路汇入展开 | 两份输入汇入中央 → 翻页 → 逐项立起 | 「主题和文档」「生成」 |
| | M09 走线流动 + 支路高亮 | 小块沿走线进目标，只亮当前支路 | 数据、传输、并行分流 |
| | M10 逐段连线 / 手绘箭头 | 从第一节点逐段连，配短标注 | 流程、关系、「连起来」 |
| | M11 拖动产生变化 | 光标/节点沿路径移动后再重连 | 「调整」「挪位置」「拖动」 |
| | M12 扫描分区识别 | 扫描线随页移动，遇区域留框归位 | 「扫描」「识别」「提取」 |
| **D 操作** | M13 界面流程演示 | 下拉选中→进度条→焦点切换→问答 | 「选择」「安装」「开始用」 |
| | M14 打字机 + 复制粘贴 | 逐字输入、整块复制、副本滑入 | 「写三行」「复制」「粘贴」 |
| | M15 播放头扫画格 | 播放头越过画格→导出→换缩略图 | 「导出」「套模板」「下一张」 |
| **E 数据** | M16 先口径后揭值 | 先亮日期/平台/单位，再揭主数字 | 任何统计数字前 |
| | M17 逐条打勾 + 趋势逐点 | 逐条进场打勾，复用数据连成趋势 | 计划→完成→成效 |
| **F 对比** | M18 分路并行合流 | 任务分 A/B 两路，结果合到确认卡 | 「A/B」「对比」「两种」 |
| | M19 双页展开 / 版式对照 | 封面内页对页展开；或两种排版并列 | 「同一内容做两种」 |
| | M20 多图接力换位 | 多张原图错峰滑入、重点停中间 | 「划着看」「这几张」 |
| **G 收尾** | M21 结果停稳 + 关键词亮 | 操作完停稳给读完，关键词分两拍 | 结论、领取方式、关注 |

> 提示音不单列模式——它是**叠加层**：给 M02/M03/M10/M12/M14/M15/M20 的关键动作帧配短音，规则见 §3.9。

## 2. 模式卡（可复制提示词模板）

每张卡的「提示词模板」**直接复制进阶段 4 的镜头表 / 阶段 5 的场景注释**，把 `［］` 按本期台词与章节填实。模板刻意写成工具箱那种「听到 X 就让 Y 动」的口吻——这是 agent 最容易照着实现的形式。所有 `at(n)` 的 n 是**本章台词行索引**，查 `timeline.json`。

### A · 开场钩子

#### M01 前后景大字遮挡
- **解决**：开场/章节揭题要"有层次、不像一页 PPT"。
- **提示词模板**：
  > 用本期主标题做前后两层：后景大字压在主体区，**前景放一个384 词元素（声波头像 / 工具 logo / 资料卡）压住标题下缘约 1/4**，让字在物后面但要能读全。听到主题词时后景字从两侧揭开停稳；前景元素晚 4 帧进场压住。全程沿原声时间轴，不用真人抠像。画面文字不超过 3 块。
- **实现**：两个绝对定位层，后景 `fontSize 110~140`、前景 `Card` 或 `Img` 覆盖 `bottom` 一小条；进场用 `popIn(local, at(0)+n)`；揭开用 `clipPath: inset(0 X% 0 X%)` 随 local 收窄（见 `Opening.tech.tsx` 全息卡）。
- **素材**：纯代码即可；有用户真人/C 档素材才用真实遮挡（`12` §0）。
- **反模式**：前景压住关键字导致读不出；字全露 = 没有层次感，白做。

#### M02 真实成果首帧
- **解决**：黄金三秒要"一眼看到真东西"，而不是先铺背景。
- **提示词模板**：
  > 首帧就铺开本期的真实成果（成品图 / 数据 / 截图），配一句问题立题。主图保留可辨识的字与场景，用本期色板压一道统一色调。首句结束时收起图卡接正文，同一段音轨连续。所有动作从真实口播起点触发。
- **实现**：`staticFile('assets/xxx.png')` + `<Img>`（`12` §6）；收起用 `scale 1→0.85` + 淡出；首帧 `frame 0` 就要有运动（缓推近 `1.0→1.04`）。
- **素材**：**A 档必用**（真实成果，代码画不像）。无成品则退到 M01。
- **反模式**：用网搜的无关漂亮图——首帧道具必须是本期真结果，观众一眼能看出是不是。

#### M03 数字重音上移
- **解决**：口播喊出关键数字时，画面要有"重音"回应。
- **提示词模板**：
  > 把关键数字放在主体区，听到这个数字时短距离上移（约 24~40px）停稳，字号比周围大 1 档；配 `fmt()` 千分位滚动或直接从 0 冲到目标值。数字落地后停稳至少 1 秒让观众读完。日期/平台/单位（如有）已在上一拍交代。
- **实现**：`interpolate(local,[at(n),at(n)+10],[y0,y0-32])` + `Easing.out(Easing.cubic)`；滚动见 `10` §4 数字滚动。
- **反模式**：数字没有前置口径（哪天、谁、什么单位）就亮 → 数据不可信，见 M16。

#### M04 逐格点亮预告
- **解决**：列举多内容前，先让观众有"有 N 个"的预期。
- **提示词模板**：
  > 画面先出 N 个空刻度/占位格，听到「N 个」时从左往右逐格点亮（每格间隔 3~5 帧），点亮到一半时切正文；占位格保留到本页结束。点亮顺序就是口播列举顺序。
- **实现**：`Array.from({length:N})` + 每格 `opacity: pop(local, at(n)+4+i*4).opacity`；点亮色用 `C.cyan`，未亮用 `C.cardBorder`。
- **反模式**：一次性全亮 = 失去预告意义；点亮顺序和列举顺序不一致 = 观众对不上。

### B · 文字强调

#### M05 重点词扫入
- **解决**：一屏只有短句，但哪几个字是重点要看得出来。
- **提示词模板**：
  > 用字幕当句的起止帧定位，把当句短句放大放在主体区。关键词用本章识别色（沿用 `C` 语义色）从左向右扫出一层底色（宽度随 local 从 0 长到词宽），不遮盖主图/主标题；非关键词保持白字。关键词出现帧对齐该词发声。
- **实现**：关键词包一层 `position:relative`，底下绝对定位一条 `height:0.9em; width: sweep*100%` 的半透明色块（如 `rgba(34,211,238,0.28)`），`sweep = interpolate(local,[at(n),at(n)+12],[0,1])`。
- **反模式**：底色铺满整句（等于没强调）；用红底压在正文上读不清。

#### M06 一笔引线
- **解决**：标题和它指的图/证据之间要有"关系"，不能各放各的。
- **提示词模板**：
  > 听到章节名/工具名时揭开大标题，标题下方引出一条线，**由同一笔向右画出并弯折到主图边缘**，线的终点停在主图轮廓上。换章节时更换落点与识别色。
- **实现**：`<svg><path>` + `strokeDasharray`/`strokeDashoffset` 随 local 递减（一笔画出）；或简单版：水平段 + 斜段两个 `div` 宽度随 `interpolate` 增长。
- **反模式**：引线画到一半停住悬空；线穿过文字/字幕区。

#### M07 几何擦除换版
- **解决**：底图/版式要切换，但硬切太生硬。
- **提示词模板**：
  > 报日期或转折词时，用一道几何擦除（从左到右的矩形 `clip-path`）把旧底图换成新标题/新底图，擦除边缘留一条 2px 高亮线随帧移动。换完停稳，不在擦除过程中堆文字。
- **实现**：新层 `clipPath: inset(0 ${(1-p)*100}% 0 0)`，`p = interpolate(local,[at(n),at(n)+14],[0,1])`；边缘高亮线 `left: p*100%`。
- **反模式**：擦除时两层文字重叠可读成乱码。

### C · 过程演示

#### M08 双路汇入再展开
- **解决**：讲"两个东西合成一个结果"（输入→生成、文档→图表）。
- **提示词模板**：
  > 画面中央留一个工作区。讲到 A 和 B 时，让两份输入从左右两路汇入中央（沿短弧线或直线，各晚 4 帧）。说出「生成」时工作区纸面翻开展示页，结果从纸面逐项立起（每项间隔 5 帧）。最后留屏让人看清成品。
- **实现**：两路用 `interpolate(local,[at(n),at(n)+12],[x0,xCenter])`；展开用 `transform: perspective(800px) rotateX(80deg→0)`；逐项立起用 `popIn(local, at(n)+20+i*5)`。
- **素材**：输入物是真实文档/海报则用 `12` 的 A 档图，否则代码画 mockup。
- **反模式**：两路同时到达 = 分不清；结果一次性铺满（违反铁律一）。

#### M09 走线流动 + 支路高亮
- **解决**：讲数据/请求/任务的流向与并行分流。
- **提示词模板**：
  > 画两个清晰节点（来源、目标）用细走线连接。说到数据时出现小块，说到来源时小块聚集，说到传输时小块沿线进入目标并高亮经过的节点。要区分可选路径时**只改变该支路的亮度和连接状态**，主线保持易读。
- **实现**：小块位置 `interpolate(local,[at(n),at(n)+20],[0,1])` 再映射到 SVG path 上的点；主线恒亮，支路用 `opacity: 0.25 + 0.7*active`。
- **反模式**：所有支路一起亮/一起动 → 分流语义丢失。

#### M10 逐段连线 / 手绘箭头
- **解决**：讲流程、关系图、"从 A 连到 B"。
- **提示词模板**：
  > 用图/示意图作底层（真实原图或代码 mockup）。从第一个节点出发，口播讲到下一段时**逐段**把线连出去，线头跟到下一拍才展开完整关系图；每段线旁紧跟一个短标注，标注字 ≤8 字。
- **实现**：每段一个 `<line>` 或 `<path>`，`strokeDashoffset` 用 `interpolate(local,[at(n+i),at(n+i)+10],[len,0])`；节点 `popIn(local, at(n+i)+2)`；标注同帧进场。
- **素材**：真实流程图优先（`12` A/B 档），代码画不清时用 ImageGen 补概念图并标"示意"。
- **反模式**：一次性画完整张关系图 —— 观众跟不上也说不清"现在讲哪段"。

#### M11 拖动产生变化
- **解决**：讲"调整、挪动、拖动后重连"这类操作结果。
- **提示词模板**：
  > 先展示原始状态（完整卡片/组装态/图表）。口播点到要调整的对象时，让光标/节点**沿可见拖动路径**移动到新位置（显示控制手柄/吸附参考线），跟随下一句把新的连接从端点画到真实目标。改完停稳。
- **实现**：拖动对象 `transform: translate(x,y)`，`x/y = interpolate(local,[at(n),at(n)+16],[x0,x1])`；参考线 2px 虚线；重连接 M10。
- **反模式**：对象瞬移（无路径）→ 观众看不出"被拖过"；用静态截图演示拖动 → 铁律四违规。

#### M12 扫描分区识别
- **解决**：讲扫描、识别、提取、分块处理。
- **提示词模板**：
  > 导入一张含多个区域（正文/表格/公式）的文档示意，保留清晰页边距。说到扫描时让一条窄扫描线随画面从上到下移动，遇到对应区域留下定位框；按口播顺序把各块结果移入同一右栏，收尾同时显示原文档和识别结果。
- **实现**：扫描线 `top: interpolate(local,[at(n),at(n)+len],[y0,y1])`；定位框 `border: 2px solid C.cyan` + `popIn`；结果块 `translateX` 从文档移到右栏。
- **反模式**：扫描线匀速划过但定位框乱闪 → 观众不知道扫到了什么。

### D · 操作演示

#### M13 界面流程演示
- **解决**：讲工具怎么装、怎么配置、怎么提问。
- **提示词模板**：
  > 用一个桌面窗口演示完整流程，窗口位置全程不跳。说到选择时展开下拉并选中目标；听到安装时填充进度条；说到开始使用时把焦点切到输入框，依次出现提问和回答。继续讲配置时把次要选项折叠，让对话结果停稳可读。
- **实现**：一个 `Card` 当窗口，内部按 `at(n)/at(n+1)/…` 逐段揭示下拉、进度条、输入框、问答气泡；进度条 `width: p*100%`。
- **素材**：真实界面截图/录屏按 `12` 取，压统一色调；无素材则代码画 mockup（本 skill 默认）。
- **反模式**：窗口位置每步都变 → 观众丢失上下文。

#### M14 打字机 + 复制粘贴
- **解决**：讲"写 prompt、复制、粘贴、换个地方继续用"。
- **提示词模板**：
  > 便笺和输入框共用同一底色。按口播节奏逐字输入三行（每行起点对齐该行发声），输入完把整张内容做成一份浅色副本滑动突出（复制），再点开新对话，把副本滑入输入框（粘贴），点击/落位卡重音。同一张便笺贯穿始终。
- **实现**：逐字 `chars.slice(0, Math.floor(interpolate(local,[at(n),at(n)+18],[0,chars.length])))`；副本 `translateX` 位移 + 变色；光标 `sin(local/6)` 闪烁。
- **反模式**：三行一次出现（没有打字过程）；换一场景就换了张便笺（观众以为讲别的）。

#### M15 播放头扫画格
- **解决**：讲导出、套模板、批量换图。
- **提示词模板**：
  > 把时间线、画格和预览区放同一面板。提到导出时播放头扫过画格，显示导出的文件；提到存模板时把时间线和关键帧收拢到模板条目；提到套用时保持轨道和版式，让缩略图逐个换成新素材并继续播放。
- **实现**：播放头 `left: p*width`（p 随 local）；画格高亮 `i <= floor(p*N)`；缩略图逐个 `popIn` 替换。
- **反模式**：轨道版式在"套模板"前后变了 → 看不出是同一模板。

### E · 数据揭示

#### M16 先口径后揭值
- **解决**：任何统计数字，先交代来源才可信。
- **提示词模板**：
  > 分步显示：先出日期，再出平台/对象，再出单位，最后才揭主数字；主数字用放大字号和识别色，若有排名则在下一拍点亮。全程只表示这一个平台/口径的数据，不扩写成全局结论。
- **实现**：四段分别 `popIn(local, at(n)+i*8)`；数字落地后停稳 ≥30 帧；单位小字号紧跟数字右侧。
- **反模式**：先亮大数字再补口径 → 观众误读范围；把单平台数据说成全网。

#### M17 逐条打勾 + 趋势逐点
- **解决**：讲计划→完成→成效，或任何"累积出结果"。
- **提示词模板**：
  > 用一张连续的记录界面：提到计划时逐条列出项目，讲到完成情况时按组亮起勾选，提到数值时显示对应字段。到了成效段，**复用前面出现过的数据**把趋势线逐点画出，不引入新数字。
- **实现**：勾选用 `local >= at(n+i)` 切换图标；趋势 `strokeDashoffset` 逐点；数值标注"示意"如为演示数据。
- **反模式**：趋势线用的是前面没出现过的新数据 → 观众无法验证。

### F · 对比合流

#### M18 分路并行 + 结果合流
- **解决**：讲 A/B 测试、两条路线、两种方案的对比。
- **提示词模板**：
  > 用一张独立标注的小图解说明对比。把同一任务分进 A、B 两条轨道，分别推进并标记各自结果；结束时把选中的有效结果连到一张确认卡。分流、启动、合流三个节点各给一个短提示音（压低），按关键词落点，不改原声时轴。
- **实现**：两轨 `translateY` 分叉 → 各自进度条 → 合流 `<path>` 用 M10 画法；确认卡 `popIn(local, at(n)+30)`。
- **反模式**：两轨进度完全同步 → 看不出是比较；结论卡盖住两条轨的结果。

#### M19 双页展开 / 版式对照
- **解决**：讲同一内容的不同排版、封面与内页。
- **提示词模板**：
  > 先给一个案例卡，跟着「同一段内容做两种格式」并列放大两种排版，保留尺寸和文字差异供对照；或借纸面折合把封面与内页展开成对页，落稳后保留对照阅读。
- **实现**：两卡并排 `popIn` 错峰；折合用 `rotateY(-18deg→0)` + `transform-origin` 在书脊侧。
- **反模式**：两种排版缩放不一致 → 无法公平对照。

#### M20 多图接力换位
- **解决**：讲"这几张图""划着看"，多素材要逐张登场。
- **提示词模板**：
  > 让多张原图沿横轴错峰滑入，分别停住，重点那张停在画面中间；局部去掉空白边缘只留主体。落位、切换各配一个短音。结束时可把这几张一起收进文件夹或评论区输入框。
- **实现**：每张 `translateX: interpolate(local,[at(n+i*2),at(n+i*2)+12],[x0,0])` + `zIndex` 递增；重点张停留时长 > 其余。
- **素材**：`12` A/B 档（真实图文），统一压色后进场。
- **反模式**：多图同时堆成一屏（违反铁律一、二）。

### G · 收尾

#### M21 结果停稳 + 关键词分两拍
- **解决**：讲完要让人看清结果、记住动作。
- **提示词模板**：
  > 操作讲完后画面停稳（≥1 秒）让人读完结果；收尾回到开场构图，按原声先亮出第一拍（关键词/成果），再亮第二拍（领取方式/关注/名称）。低对比度的项目名可滚动带出结尾。始终留出字幕空间。
- **实现**：结果层 `sceneOpacity` 保持 >1s；两拍 `popIn(local, at(n)+0)` / `popIn(local, at(n)+24)`；滚动带 `translateX` 线性。
- **反模式**：结果一闪就切走；用「点赞关注」代替本片结论（见 `02` 结尾回扣）。

## 3. 选动作的判定（阶段 4 用）

1. **这一页观众要"看懂"什么？** 是「一个东西的形状」→ A 组；「两个东西的关系」→ C/F 组；「一个操作的结果」→ D 组；「一个数字的口径」→ E 组。

## 5. 提示音叠加规则

工具箱 40 条里反复出现「给动作配短音」。本 skill 不做独立音效轨，只在两种情况下点缀：

1. **动作本身就是"落位/点击/导出/打勾"**（M04/M12/M14/M15/M20 的收束点）——每个动作 1 个短音，`volume 0.2~0.4`，起点绑该动作的 `at(n)` 帧。
2. **口播留白处**——留白 >0.5s 时可以补一个短音填满，不留白就不加。

**三条禁令**：不新建音轨（`voiceover.mp3` 唯一）；不盖过口播（超 0.4 一律降）；不用带版权的音效（CC0 来源登记进配方卡素材清单，见 `12` §4）。

## 6. 与四条铁律 / 质检的关系

- M01~M21 全部遵守「元素进场、非整页」——每个模板里的"逐项/逐段/错峰"就是铁律一的可执行形式。
- 关键词上限（铁律二）：模板里出现的文字块 ≤3~4，长句一律进字幕条；模板提示词里已写死这条。
- 动作锚点（铁律三）：每个模板的"听到 X 时"必须落成 `at(n)`，抽帧验「发声前 5 帧未出现、发声后 2 帧正在进场」。
- 静态撑不住（铁律四）：结果停稳是"给观众读完"，不是"画面冻住"——停稳期间保留一个永动小元素（进度条/呼吸光/数据轨，见 `10` §4）即可满足。
- 画质检并入 `06-qc-render.md`：用了动效库的页，抽帧必须覆盖「动作起点前 1 帧 / 起点后 2 帧 / 结果停稳帧」三帧。
