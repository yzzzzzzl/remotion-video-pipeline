# 阶段 1（模式 B）：只给主题，无参考视频

> **触发**：用户只给主题 / 文章 / 要点 / 素材名，没有视频链接或本地原片。
> **做什么**：跳过 `01-reference-teardown.md` 的 1.1~1.3（下载、抽帧、转写），**直接推导出同一张配方卡**。阶段 2~7 与模式 A **完全一致**，一行代码都不用改。
> **不新增确认门**：规格用默认值兜底，不追问用户（见 §6）。

---

## 0. 路由：先判断走 A 还是 B

| 用户给的 | 走哪 | 说明 |
|---|---|---|
| 视频链接 / 本地 MP4 | **A · 拆解**（`01`） | 下载 → 抽帧 → 转写 → 配方卡 |
| 只有一句话主题 | **B · 推导**（本文） | 主题 + 默认值 → 配方卡 |
| 主题 + 风格偏好（「竖屏、深黑荧光绿、科技感」） | **B** | 偏好**覆盖**默认值，仍不追问 |
| 主题 + 一篇文章 / 文档 / 书名 | **B** | 文字是**素材**（写稿时用），不是参考片，别去抽帧转写 |
| 主题 + 几张参考截图 / 配色图 | **B** | 截图只用来取色，不做节奏拆解 |

关键判断：**有没有可逐帧拆的原片**。没有就走 B，不要为了凑流程编一条参考片出来。

---

## 1. 最小输入集与默认值

**必需只有一项：主题（一句话）。** 其余一律用默认值，**不要问用户**（§6）。

| 项 | 默认值 | 依据 / 备注 |
|---|---|---|
| 画幅 | **1920×1080 @30fps** 横屏 | 通用横版/B 站；用户明确说抖音/小红书/竖屏才改 1080×1920（坐标换算见 `10-first-15s.md` §10） |
| 时长 | **2:30 ~ 3:00** | TTS 约 240 字/分钟 → 稿子约 600~720 字（`02` §2.1） |
| 章节数 | 开场 + **3~4 章** + 收尾 | 每章只扛一个核心观点（`02` §2.1） |
| 画风 | 按主题查 `10-first-15s.md` §5 映射表 | 无法归类 → 科普类（深蓝 + 青） |
| 字体 / 色板 / 母题 | 随画风走 | 全片共用一套 `C`（`05`） |
| 结构 | Hook 四拍 → 并列观点章 → 回扣结尾 | `10` §3、`02` §2.1 |
| 节奏 | 正片 4~15s/页；**开场 ≥6 页、单页 ≤2.5s** | `04`、`10` §1 |
| 总览页复用 | **是**，3~4 次 | `04` 的并列结构是复用基础 |
| 配音方式 | **阶段 1 不定** | G1 才问（`09`） |
| 结尾 | 回扣 Hook 的矛盾，不用「点赞关注」 | `02` §2.1 |

> 用户主动补的偏好优先于默认值，写进配方卡并标注「来源：用户指定」。

## 2. 推导式配方卡（逐项填，不许留空）

配方卡模板仍用 `01` §1.4 那张，但每个字段要标明**来源**，且**不留「待定」**——`05` 与 `10` §5 都要读它，留空后面就断输入。

| 配方卡字段 | A 模式怎么来 | B 模式怎么来 |
|---|---|---|
| 画幅 / 帧率 | `ffprobe` 原片 | 默认值 / 用户指定 |
| 底色 / 主色 / 强调色 | 抽帧取色 | `10` §5 映射表 |
| 主题画风 | 逐帧读版式 | 主题关键词归类（技术 / 书籍 / 财经 / 科普 / 极简） |
| 版式 / 字幕 / 装饰 | 逐帧读 | `Chrome.tsx` 底座默认（`05` 安全区 + 常驻组件） |
| 结构章节表 | 转写空档 + 人工标注 | 主题自建骨架（§3 模板） |
| 单页最长停留 | 统计参考片切点 | 默认 4~15s（`04`） |
| 开场 15 秒 | 加密抽帧统计 | `10` §1 硬指标（≥6 页、首屏 ≤1.5s） |
| 总览页复用 | 观察参考片 | 默认「是」，3~4 次 |
| 可迁移 / 不可迁移 | 填参考片的可迁移项 | 写「**无参考片；全部为推导默认值，用户后续反馈优先覆盖**」 |

**新增一个字段**（B 模式必填）：

```markdown
## 配方卡来源
- 模式：A 拆解 / B 推导
- 输入：主题「…」+ 用户指定覆盖项（列出，没有就写「无」）
```

---

## 3. 主题 → 章节骨架模板

没有参考片骨架可沿用，就自己建一个。**并列结构是刚需**——没有「第一/第二/第三」，`04` 的总览页复用就无从谈起，画面会退化成一页页互不相关的卡片。

```
开场（0:00–0:15）  Hook 四拍：冲击 → 误区 → 拆穿 → 预告（10 §3）
第 1 章  先说结论  列出 N 个并列要点 → 总览页（都不点亮）
第 2 章  要点一    回总览页点亮① → 1~2 页解释页
第 3 章  要点二    回总览页①打勾、点亮② → 1~2 页解释页
第 4 章  要点三    回总览页②打勾、点亮③ → 1~2 页解释页
收尾     全部点亮 + 回扣开篇矛盾 + 一句结论
```

### 填好的示例

> 用户输入：`AI 做视频，门槛在流程不在工具`；附加：`竖屏、深黑荧光绿、示例素材《资本论》`（用来演示用户偏好覆盖默认横屏）

```markdown
## 配方卡来源
- 模式：B 推导
- 输入：主题「AI 做视频，门槛在流程不在工具」
- 用户指定覆盖项：1080×1920 竖屏（覆盖默认横屏）；深黑 #0A0D09 + 荧光绿 #B6E388；示例素材《资本论》

## 视觉
- 画幅/分辨率/帧率：1080×1920 @30（用户指定，覆盖默认横屏；坐标换算见 `10` §10）
- 底色/主色/强调色：#0A0D09 / #B6E388 / #6FE3D2（用户指定）
- 主题画风：技术 / AI（映射表 10 §5）
- 版式：Chrome.tsx 竖屏安全区（`10` §10 换算）；主体区居中，避开字幕条与右上声波头像
- 字幕：底部字幕条，逐字进场，最多 2 行
- 装饰：章节标签 / 帧计数器 / 进度条 / 声波头像

## 结构
| 章节 | 时长 | 作用 | 我方对应章节 |
|---|---|---|---|
| 开场 Hook | 0:00-0:15 | 数字冲击 + 否定「大模型魔法」 | ch0（7 页帧级快切） |
| 先说结论 | 0:15-0:45 | 四步流程并列要点 | ch1 总览页 |
| 流程与铁律 | 0:45-1:30 | 字幕是唯一基准 | ch2 观点↔解释页 |
| 实操：资本论 | 1:30-2:30 | 样片演示 | ch3 样片预览框 |
| 祛魅 + 收尾 | 2:30-3:00 | 规则写在 Skill 里，回扣 Hook | ch4 / ch5 |

## 节奏
- 单页最长停留：4~15s
- 开场 15 秒：≥6 页 / 首屏 ≤1.5s / 常驻科技 HUD（10 §1、§4）
- 是否有「总览页复用」：是，3 次
- 转场方式：正片淡入+36px 上滑；开场 4 帧淡入+24px 横滑

## 可迁移 / 不可迁移
- 无参考片；全部为推导默认值，用户后续反馈优先覆盖
```

## 4. 写稿差异（`02`）

- `02` §2.1 的「**同结构、换表达**：参考片的叙事骨架可以沿用」在 B 模式换成「**从主题自建骨架**」（§3），没有可沿用的原片。
- 字数预算照旧：TTS 240 字/分钟 × 目标时长；开场至少写 **4~6 句**供快切（`10` §2）。
- 每章只扛一个核心观点，用「第一 / 第二 / 第三」或「四个格子」做并列（`02` §2.1）。
- 【画面：…】标注照做，逼自己检查「这段话有没有画面可做」——纯议论段落是动画的天敌。
- 用户给的文章/文档只在**写稿**时当素材用，别拿去抽帧或转写。

## 6. 软门与「不新增确认门」

- 配方卡**照常交付给用户看**（软门：只给看、不停机等回复，见 `01` §1.5 / `09`）。
- **不要追问**：画幅、时长、配色、字体、音色、每页动画……一律用 §1 默认值，用户主动提才覆盖。
- **B 模式不是第三道门**。整条流水线仍然只有 G1 / G2 两次打断（`09`）；`10` 的开头 15 秒规范同样不是门。
- G1 仍只问一次配音方式；G2 仍必须交付音轨试听并拿到明确确认。

---

## 7. 反模式

- 编一条「参考片」出来凑流程，或把主题硬当参考片去拆解。
- 因为没参考片就追问用户十个规格问题（默认值就是为这个准备的）。
- 配方卡字段留空 / 写「待定」→ `05` 与 `10` §5 立刻失去输入。
- 画风不查映射表，一套科技模板通吃所有主题（`10` §5 三条禁止）。
- 章节没有并列结构 → `04` 总览页复用失效。
- 跳过配方卡直接写稿 → 视觉与节奏全靠临场拍脑袋。
- 把用户给的文章 / 文档当参考片去抽帧转写（它是素材）。
- 承诺「复刻某某同款」——没有参考片就没有「同款」，只能承诺「同类型知识短片」。

## 8. 与 A 模式的质量差异（诚实说明）

| | A · 拆解 | B · 推导 |
|---|---|---|
| 视觉依据 | 抽帧取色、逐帧读版式，有实证 | 映射表给合理默认 |
| 节奏依据 | 统计参考片切点 | `04` / `10` 的默认指标 |
| 结构依据 | 转写空档 + 人工标注 | 主题自建并列骨架 |
| 优势 | 能对准某条具体片子的「为什么好看」 | 起步快，零下载、零转写，主题即开工 |
| 代价 | 依赖能拿到原片（抖音要 CDP 截流） | 风格可控性下降，首版可能不是用户心里的画面 |

**弥补方式**：① 鼓励用户在主题里顺带说风格偏好（一句话即可，覆盖默认值）；② 首版后按 `06` §改稿速查低成本调整（换配色 / 重做开场都只渲染，音轨与时间轴不动）。

B 模式**不该**承诺「复刻同款」，也不该因为「没有参考片」就降低 `08` 四条铁律或 `10` 开头 15 秒的标准——那两套判据与参考片无关，照常全绿才渲染。
