# 阶段 5：视觉体系（1920×1080 横屏，默认）

底座组件在 `assets/components/Chrome.tsx`（已验证），新工程直接拷进 `src/components/`。设计规范如下，改风格时保持布局骨架不动、只换 token。

## 画布与安全区（1920×1080）

| 区域 | y 范围 | 用途 |
|---|---|---|
| 顶部状态区 | 0 ~ 130 | 章节标签（左上）、声波头像（右上，直径 ~130） |
| 主体内容区 | **130 ~ 870** | 场景组件唯一可布局区（`<Center top={…}>` 传入） |
| 字幕区 | 892 ~ 1040 | 字幕条，白字，最多 2 行 |
| 底部条 | 1040 ~ 1080 | 全宽进度条（高 8）+ 帧计数器（右下） |

主体内容**永远不要**侵入字幕区；卡片墙、多列表格等高密度页用 `top=160` 起排。

> **竖屏为按需覆盖**：仅当用户明确要求抖音/小红书竖屏时才用 1080×1920，安全区改为「顶部 0~180 / 主体 420~1450 / 字幕 1580~1780 / 底部 1780~1920」，坐标换算见 `10-first-15s.md` §10。`Chrome.tsx` 会按 `useVideoConfig()` 自动切横/竖屏坐标，场景组件不要写死字幕条 `top`。

## Token

```ts
export const C = {
  bgDeep: "#0B1526", bgLight: "#12233F",
  blue: "#3B82F6", blueLight: "#60A5FA", cyan: "#22D3EE",
  red: "#EF4444", green: "#22C55E", amber: "#F59E0B",
  white: "#F4F8FF", dim: "#8FA3C4",
  cardBg: "rgba(255,255,255,0.05)", cardBorder: "rgba(96,165,250,0.28)",
};
```

强调色语义固定：cyan = 当前提起、green = 已完成/确认、red = 否定/划掉、amber = 警告。语义色不要混用。

字号下限：正文 32、卡片标题 40、金句 52、大按钮 60。横屏主体区较矮，文字放不下优先拆页，不要缩字号或往字幕区挤。

### 主题画风选择（阶段 5 第一件事）

先从阶段 1 配方卡读主题（**A 拆解或 B 推导都行**，配方卡字段一致，见 `11-topic-only.md` §2），再按 `10-first-15s.md` §5 的映射表选「色板 + 字体 + 母题」，写进 `C` 与 `FONT/MONO`：

- **全片共用一套 token**：开场只是同一色板的高密度版本，不许开场与正片两套颜色/字体
- `Video.tsx` 的全局背景色必须 = `C.bgDeep`，换主题时一起改，否则切章会闪一下
- 禁止一套科技模板通吃：书籍/人文用深棕烫金 + 衬线 + 书页翻动，别用代码雨
- 开场从这套母题里挑 3~4 个特效做高密度版；正片沿用同一套，只降低运动密度

已验证的科技风开场实现在 `assets/components/Opening.tech.tsx`（横屏 1920×1080，正是默认画幅），竖屏按需覆盖的坐标换算见 `10-first-15s.md` §10。

## 常驻组件（Chrome.tsx 提供）

| 组件 | 说明 |
|---|---|
| `Background` | 深蓝渐变 + 72px 科技网格 + 漂移光晕（`frame` 驱动，永动） |
| `ChapterTag` | 左上角「第 N 章」胶囊，进场下滑；`tag=null` 的章不渲染 |
| `WaveAvatar` | 右上角圆形**声波头像**——没有真人出镜素材时的替身，随帧跳动的声环 |
| `SubtitleBar` | 底部字幕，**逐字进场**（reveal 按行 startFrame 起算），高亮当前字 |
| `FrameCounter` | 右下 `frame N / 总帧数` 等宽字体——程序员向彩蛋，总分母必须取 `durationInFrames` |
| `ProgressBar` | 底部进度条，按全局 frame / 总帧数 |

所有常驻组件的坐标由 `getChromeLayout(width, height)` 统一给出（默认横屏；竖屏自动切），场景组件可从 `Chrome.tsx` import 这个函数对齐安全区。

真人小窗替代方案优先级：用户素材 > 声波头像 > 纯 logo 圆窗。**不要**用静态占位图充数。

### 外部素材接入（按需）

凡真实素材能提升可信度/质感的画面（真实物件、实拍质感、场景氛围、纹理、操作录屏、图标、音效），按 `12-asset-sourcing.md` §0 的三档判据由阶段 4↔5 主动检索下载——**准入已放宽到「有它更好」，但版权/画风/元素三关否决照旧**。完整规范见 `12-asset-sourcing.md`。本阶段只负责三件事：

1. **统一画风再进场**：外部素材默认和主题色板对不上，必须先降饱和/压色/去背/统一亮度（命令见 `12` §5），处理到「和正片同一套 token」才用。跳过这步 = 视觉割裂，验收打回。
2. **落地与引用**：素材放 `remotion-project/public/assets/`，组件里用 `staticFile('assets/xxx.png')` 引用；视频用 `<OffthreadVideo muted>`，不用 `<Video>`（渲染掉帧）。音轨仍以 `voiceover.mp3` 为唯一主音轨，素材音效压到 0.2~0.4 并挂台词锚点。
3. **素材也要守四条铁律**：作为元素错峰进场，不做整页背景；停留 >3s 挂缓推近/平移/遮罩；进场时刻用 `at(i)` 从 timeline 换算，不拍常数。详见 `12` §7。

### 开场常驻层（仅第 0 章）

开头 15 秒可挂一层低透明度 HUD（REC 状态、解码帧号、十六进制数据轨、四角 L 框、扫描线、刻度），让画面「一直在动」：

- 透明度 0.3~0.6、`pointerEvents:none`，不抢主体；装饰小字仍计入一屏文字元素数
- 避开字幕条 / 右上声波头像 / 右下帧计数器 / 左上章节标签；说明行放字幕条**上方**空隙
- **只在第 0 章渲染**，章末必须完全消失（切章后抽 1 帧逐项核对）
- 全部用确定性 `sin(local)` 或 `floor(local/n)`，**禁止 `Math.random()`**（逐帧渲染会抖动）
- 不用大圆环/圆圈当画面正中装饰；用 L 形角标、方括号、终端框
- 完整规则见 `10-first-15s.md` §4；默认横屏直接用 `Opening.tech.tsx` 坐标，竖屏按需换算见 `10` §10

## 场景层结构

```
Video.tsx（编排：音轨 + 章节路由 + 全局组件）
 └─ scenes/Scenes.tsx（每章一个 Scene 导出 + XXX_SHOTS 镜头表）
     └─ ShotEngine（ShotSequence：按台词行索引选页 + 转场）
```

- `Video.tsx` 只做四件事：算当前章/当前行、路由 Scene、渲染全局组件、结尾 24 帧淡出黑
- 场景组件**只依赖** `{ local, len, curLine, lines }` props（`lines` 已过滤成本章、带 relStart）
- 基础动效用 `Chrome.tsx` 的 `popIn(local, delay)`（透明度+上移）与 `spring`；**delay 用 `at(i)` 换算**（台词锚点，见铁律三），不要拍常数
- **讲解型动作**（逐项进场、扫描线、走线连线、数据流、打字机、数字滚动、划掉、扫入高亮、翻页、结果停稳）从 `Motion.primitives.tsx` 直接 import，同样传 `local` + `delay={at(i)}`。选哪种动作按 `13-motion-library.md` §3 的判定（先定这页要让观众看懂什么，再挑主动作，一页一个）
- 分工：`10-first-15s.md` §4 的特效管**开场装饰质感**，`13-motion-library.md` 管**正片「讲到什么就演什么」**；同一页可叠加——语义动作是骨架，装饰特效是质感
- mockup 卡片（窗口框、代码块、目录树）用 `MONO` 等宽字体 + `cardBg/cardBorder`，别用纯白底

## 字幕逐字进场实现要点

- reveal 进度 = `(frame - line.startFrame) / (line.durationFrames × 0.8)`（后 20% 留给收稳）
- 每字 opacity + translateY 微动，当前朗读字用 `C.cyan` 高亮
- 行切换不做硬切：上一行提前 3 帧淡出
- 标点不占 reveal 帧数
