# MOTION-DIRECTOR.md — 选效果、定时序、控密度

> 阶段 4 分镜设计时查。目标不是「把 31 个效果塞进片子」，而是**每一页让观众看懂一件事**。
> 索引在 `INDEX.md`；单个效果的规则在那张卡的 `MOTION.md`；实现细节看 `MOTION-TECHNIQUE.md`。

## 1. 三问定一个效果

对每一页依次问，答不出来就说明这页不该单独存在：

1. **这一页观众要「看懂」什么？**
   - 一个东西的形状 → A 组（钩子）
   - 一句话里哪个词重要 → B 组（文字）
   - 两个东西的关系 / 流程 / 数据流向 → C 组（过程）
   - 一个工具怎么用 → D 组（操作）
   - 一个数字的口径 → E 组（数据）
   - 两种方案 / 多张素材 → F 组（对比）
   - 结论、读完就走 → G 组（收尾）
2. **台词里有没有触发词？** 触发词就是动作锚点，`at(n)` 绑到那句。
   - 「六个 / 几个」→ `cell-preload`；「8 个 / 59.2 万亿 / 第 1」→ `number-accent`
   - 「其实 / 但是 / 日期」→ `geometric-wipe`；「扫描 / 识别 / 提取」→ `scan-zones`
   - 「生成 / 汇入」→ `dual-merge`；「复制 / 粘贴」→ `typewriter-copy`
   - 「导出 / 套模板」→ `playhead-frames`；「A/B / 对比 / 两种」→ `parallel-merge` / `spread-pages`
   - 「这几张 / 划着看」→ `image-relay`；「最后 / 结论 / 领取」→ `result-hold`
3. **这一页是钩子还是结论？** 开场 → A 组 + H 组装饰；章末 → `checklist-trend` / `result-hold`；中间解释 → C/D/E/F 组。

**每章一个可辨认的主动作**：一章里挑 1 个主模式反复用、用透，比每页换一个花活更强。不同章可以共用同一底色（`05-visual-system.md` 的全片 token）。

## 2. 语义动作 vs 装饰特效

| | 语义动作（A~G 组） | 装饰特效（H 组） |
|---|---|---|
| 解决什么 | 讲到什么就演什么 | 让画面一直在动、有质感 |
| 何时用 | 正片解释页 | 开场 15 秒为主 |
| 一页用几个 | **1 个主动作** | 1~2 个补运动密度即可 |
| 能否叠加 | 是骨架 | 叠在骨架上，不替代骨架 |

反模式：**开场堆语义动作**（观众还没进入主题就被解释淹没）；**正片只上装饰**（好看但没讲清任何东西）。

## 3. 主题 → 推荐组合（自行决定，不追问用户）

| 主题 | 主动作候选 | 装饰候选 | 色板/字体母题沿用 `10-first-15s.md` §5 |
|---|---|---|---|
| 技术 / AI / 工具教程 | `ui-flow`、`typewriter-copy`、`flow-dots`、`scan-zones` | `code-rain`、`hud-layer`、`terminal-type`、`counter-roll` | 深黑 + 荧光绿 + 青，MONO |
| 数据 / 成绩 / 规模 | `context-then-value`、`checklist-trend`、`number-accent` | `equalizer-bars`、`counter-roll`、`hud-layer` | 深色 + 单一强调色，等宽数字 |
| 产品 / 核心概念 | `dual-merge`、`holo-reveal` 式揭示、`spread-pages` | `holo-reveal`、`slow-push` | 低饱和底 + 一笔高亮 |
| 破除误区 | `geometric-wipe`、`strike-stamp` | `strike-stamp`、`rgb-glitch` | 白底/深底 + 红+青 |
| 书籍 / 人文 / 历史 | `leader-line`、`image-relay` | `slow-push(mode="flip"/"gild")` | 暖白 + 烫金 + 衬线 |
| 流程 / 生态 / 兼容性 | `draw-path`、`node-connect`、`parallel-merge` | `node-connect`、`hud-layer` | 深色 + 单色连线 |

**开场 15 秒例外**：这里允许 7~9 页高密度快切，单页 ≤75 帧、首屏 ≤45 帧、frame 0 就在动；装饰特效挑 3~4 个，HUD 只在第 0 章、450 帧后消失。

## 4. 时序怎么排（铁律三的可执行形式）

1. 从 `timeline.json` 查本章台词行 → `at(i)` 得到本页帧偏移。
2. 每个效果卡 §2 给了建议触发拍与建议时长（帧）。**把触发帧填进 `delay`，不要拍秒数。**
3. 一页内元素按口播顺序错峰：先标题 → 再主图 → 再证据 → 最后结论。
4. 抽帧验两帧：「发声前 5 帧还没出现」「发声后 2 帧正在进场」。
5. 改文案只改 `scenes.json` 重新生成 `timeline.json`，动画代码不动。

## 5. 密度上限

- 正片一个模式吃 1~2 页即可，别把 21 个语义动作往 3 分钟片子里塞。
- 一屏文字元素 ≤5（主画面 ≤3~4），单个 ≤12 字；完整句子只进字幕条。
- 任何元素停留 >3s 必须挂运动；停稳期用永动小元素，不是把主动作循环播放。
- 一页停留不超过 15 秒（观点页 ↔ 解释页交替），信息超载的解法是**拆页**，不是缩字号。

## 6. 选择自检卡（每页过一遍）

- [ ] 能用一句话说清这页让观众看懂什么
- [ ] 主动作只有 1 个，且触发词在台词里能找到
- [ ] `delay` 来自 `at(i)`，不是拍出来的秒数
- [ ] 装饰特效不超过 2 个，且不与主动作抢同一区域
- [ ] 停稳期有永动小元素，或停稳 ≥1s
- [ ] 文字块 ≤3~4、句子进字幕条
- [ ] 开场装饰：frame 450 后无残留
