# Keyword Sweep — 重点词扫入 · Motion Prompt

> 关键词底下一条半透明识别色从左扫出，不遮盖文字本身；非关键词保持白字。
>
> 来源 `M05` ｜ 分类 **B · 文字强调** ｜ 组件 `SweepHighlight` ｜ 建议时长 10~18 帧

## 1. 它是什么，不是什么

关键词底下一条半透明识别色从左扫出，不遮盖文字本身；非关键词保持白字。

**不是**：不是整句铺底色；底色铺满整句等于没强调。

## 2. 触发词与时机

- **触发词**：当句重音词、关键结论、这个概念
- **时序**：关键词发声帧起扫入 12 帧；与字幕条当句起止帧对齐。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

短句放大放主体区；关键词包一层 position:relative；整屏文字块 ≤3。

## 4. 原生动作（菜单，按需取用）

- **扫入＝指认重点**｜适合：术语、结论词、工具名
- **识别色＝全片统一语义**｜适合：同一概念反复出现
- **扫完停稳＝阅读时间**｜适合：短金句

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <SweepHighlight local={local} delay={at(1)}>关键词</SweepHighlight>
2. 默认色 rgba(34,211,238,0.28)，主题换色时改 color
3. 底色 zIndex:-1 保证不遮字

```tsx
import { SweepHighlight } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<SweepHighlight local={local} delay={at(0)} style={{fontSize:64}}>关键词</SweepHighlight>
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 底色铺满整句
- 用红底压正文读不清
- 关键词出现帧与发声帧错位

## 7. 变化空间（同一效果的不同用法）

- 下划线式扫入
- 半透明块扫入
- 反色扫入

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
