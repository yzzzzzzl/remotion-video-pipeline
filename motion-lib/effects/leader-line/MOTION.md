# Single Leader Line — 一笔引线 · Motion Prompt

> 标题下引一笔线，由同一笔向右画出并弯折到主图边缘，线的终点停在主图轮廓上。
>
> 来源 `M06` ｜ 分类 **B · 文字强调** ｜ 组件 `LeaderLine` ｜ 建议时长 12~20 帧

## 1. 它是什么，不是什么

标题下引一笔线，由同一笔向右画出并弯折到主图边缘，线的终点停在主图轮廓上。

**不是**：不是悬空半截线；线不能穿过文字或字幕区。

## 2. 触发词与时机

- **触发词**：章节名、工具名、看这里
- **时序**：标题/工具名发声帧起一笔画出 14 帧；终点落在主图边缘后停稳。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

水平段 + 斜段组成折线；终点距主图轮廓 0~8px。

## 4. 原生动作（菜单，按需取用）

- **一笔写出＝建立关系**｜适合：标题指向证据、工具指向结果
- **折线弯折＝绕开障碍**｜适合：文字与主图错位的版式
- **终点发光＝落点确认**｜适合：关键证据

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <LeaderLine x1={…} y1={…} x2={…} y2={…} local={local} delay={at(0)} />
2. 内部用 pathLength=1 + dashoffset，免算线长
3. 换章节时同时换落点与识别色

```tsx
import { LeaderLine } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<LeaderLine x1={120} y1={180} x2={620} y2={320} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 线画到一半悬空
- 线穿过字幕区
- 引线指向错误对象

## 7. 变化空间（同一效果的不同用法）

- 直角引线
- 斜线引线
- 双段折线引线

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
