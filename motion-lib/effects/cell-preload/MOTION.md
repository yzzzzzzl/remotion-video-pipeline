# Cell Preload Preview — 逐格点亮预告 · Motion Prompt

> 先出 N 个空占位格，听到「N 个」时从左往右逐格点亮，每格 3~5 帧，点亮顺序就是口播列举顺序。
>
> 来源 `M04` ｜ 分类 **A · 开场钩子** ｜ 组件 `PulseCells` ｜ 建议时长 16~40 帧

## 1. 它是什么，不是什么

先出 N 个空占位格，听到「N 个」时从左往右逐格点亮，每格 3~5 帧，点亮顺序就是口播列举顺序。

**不是**：不是一次性全亮；点亮顺序和列举顺序必须一致。

## 2. 触发词与时机

- **触发词**：六个、几个、有 N 个
- **时序**：「N 个」发声帧起，每格间隔 gap=4 帧；点亮到一半时可切正文，占位格保留到本页结束。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

一排小方块（16px）+ 下方短标签；格数 N 与口播列举数严格相等。

## 4. 原生动作（菜单，按需取用）

- **逐格点亮＝建立预期**｜适合：列举、清单、步骤数
- **占位格＝未完成感**｜适合：预告后续内容
- **点亮到一半切页＝节奏钩子**｜适合：长清单

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <PulseCells count={6} local={local} delay={at(1)} gap={4} />
2. 点亮色用主题识别色，未亮用 cardBorder
3. 和 StaggerList 叠加时共用一个 delay

```tsx
import { PulseCells } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<PulseCells count={6} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 一次性全亮
- 格数与列举数不符
- 点亮顺序与口播顺序不一致

## 7. 变化空间（同一效果的不同用法）

- 刻度尺预告
- 进度点预告
- 清单方块预告

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
