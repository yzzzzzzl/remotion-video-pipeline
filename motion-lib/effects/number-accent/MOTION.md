# Number Accent Lift — 数字重音上移 · Motion Prompt

> 口播喊出关键数字时，大字短距上移 24~40px 停稳，字号比周围大一档，滚动到目标值。
>
> 来源 `M03` ｜ 分类 **A · 开场钩子** ｜ 组件 `NumberAccent` ｜ 建议时长 24~36 帧

## 1. 它是什么，不是什么

口播喊出关键数字时，大字短距上移 24~40px 停稳，字号比周围大一档，滚动到目标值。

**不是**：不是无口径的大数字；没有前置口径先走 context-then-value。

## 2. 触发词与时机

- **触发词**：8 个、59.2 万亿、第 1
- **时序**：数字发声帧触发滚动 + 上移；落地后停稳 ≥30 帧。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

数字独占主体区；单位小字号紧跟右侧；周围文字块 ≤3。

## 4. 原生动作（菜单，按需取用）

- **上移重音＝强调**｜适合：数量、排名、耗时
- **滚动到值＝过程感**｜适合：从 0 冲到目标值
- **停稳＝读数时间**｜适合：核心指标

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <NumberAccent to={59200} format="comma" local={local} delay={at(2)} />
2. 上移量由 NumberAccent 内置 32px，可包一层 style 覆盖
3. 口径先在上一拍交代

```tsx
import { NumberAccent } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<NumberAccent to={59200} format="comma" local={local} delay={at(0)} style={{fontSize:96}} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 数字没有前置口径就亮
- 滚动结束立刻切走
- 数字与单位分在两页

## 7. 变化空间（同一效果的不同用法）

- 排名数字重音
- 耗时数字重音
- 金额数字重音

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
