# Two Inputs Merge — 双路汇入再展开 · Motion Prompt

> 两份输入从左右两路汇入中央工作区，说出「生成」时纸面翻开展示结果，结果逐项立起。
>
> 来源 `M08` ｜ 分类 **C · 过程演示** ｜ 组件 `DualMerge` ｜ 建议时长 30~60 帧

## 1. 它是什么，不是什么

两份输入从左右两路汇入中央工作区，说出「生成」时纸面翻开展示结果，结果逐项立起。

**不是**：不是两路同时到达；结果也不能一次性铺满（违反元素进场铁律）。

## 2. 触发词与时机

- **触发词**：主题和文档、两份输入、生成
- **时序**：输入 A 与 B 各晚 4 帧汇入（12 帧）；「生成」帧触发翻页（+16 帧）与逐项立起（gap=5）。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

中央工作区；左右各一张输入卡；结果卡 perspective(900px) rotateX(80°→0)。

## 4. 原生动作（菜单，按需取用）

- **汇入＝合成语义**｜适合：文档+主题、数据+模板
- **翻页＝结果出现**｜适合：生成、导出、揭晓
- **逐项立起＝结果可读**｜适合：清单式输出

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <DualMerge left={…} right={…} result={…} local={local} delay={at(1)} resultDelay={18} />
2. 结果项用 StaggerList 逐项进
3. 真实文档素材走 12 A 档，否则代码画 mockup

```tsx
import { DualMerge } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<DualMerge left={<div>A</div>} right={<div>B</div>} result={<div>RESULT</div>} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 两路同时到达分不清
- 结果一次性铺满
- 翻页时窗口位置乱跳

## 7. 变化空间（同一效果的不同用法）

- 文件+提示词生成报告
- 图片+文字生成海报
- 数据+模板生成图表

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
