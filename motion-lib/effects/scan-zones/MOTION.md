# Scan & Zone Recognition — 扫描分区识别 · Motion Prompt

> 窄扫描线随画面从上到下移动，遇到对应区域留下定位框，按口播顺序把各块结果移入右栏。
>
> 来源 `M12` ｜ 分类 **C · 过程演示** ｜ 组件 `ScanZones` ｜ 建议时长 50~80 帧

## 1. 它是什么，不是什么

窄扫描线随画面从上到下移动，遇到对应区域留下定位框，按口播顺序把各块结果移入右栏。

**不是**：不是扫描线匀速划过但定位框乱闪；观众必须知道扫到了什么。

## 2. 触发词与时机

- **触发词**：扫描、识别、提取、分块处理
- **时序**：「扫描」发声帧起移动 60 帧；每个定位框在自己区域的 at 帧 pop。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

文档示意保留页边距；定位框 2px 识别色；右栏统一放识别结果。

## 4. 原生动作（菜单，按需取用）

- **扫描线＝正在识别**｜适合：文档、图像、表格
- **定位框＝命中区域**｜适合：多个分区依次处理
- **结果移入右栏＝汇总**｜适合：提取结果对比原文档

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ScanZones local={local} delay={at(2)} from={140} to={760} zones={[…]} />
2. zone.at 用台词行索引换算，不拍秒数
3. 收尾同时显示原文档与结果

```tsx
import { ScanZones } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ScanZones local={local} delay={at(0)} from={80} to={600} zones={[{top:140,left:60,width:420,height:80,at:10},{top:300,left:60,width:420,height:80,at:30}]} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 定位框乱闪
- 扫描线与口播顺序不一致
- 结果块没有来源对应

## 7. 变化空间（同一效果的不同用法）

- 文档分区识别
- 图像区域检测
- 表格字段提取

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
