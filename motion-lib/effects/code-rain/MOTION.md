# Hex Code Rain — 代码雨 / 十六进制数据轨 · Motion Prompt

> 用 (i*73 + floor(local/3)*17 + r*131) % 4096 这类确定性 seed 生成十六进制数据轨。
>
> 来源 `10 §4` ｜ 分类 **H · 开场装饰** ｜ 组件 `CodeRain` ｜ 建议时长 30~150 帧

## 1. 它是什么，不是什么

用 (i*73 + floor(local/3)*17 + r*131) % 4096 这类确定性 seed 生成十六进制数据轨。

**不是**：不是真随机雨；每帧独立渲染必须得到同一个序列。

## 2. 触发词与时机

- **触发词**：技术、AI、工具教程
- **时序**：触发后每 3 帧换一行 seed；章末完全卸载。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

小号等宽字、低透明度；放在字幕上方空隙或侧边。

## 4. 原生动作（菜单，按需取用）

- **数据轨＝系统感**｜适合：技术/AI 主题
- **确定性刷新＝稳定质感**｜适合：长时间停留
- **低透明度＝背景层**｜适合：不抢主体

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <CodeRain rows={12} cols={24} local={local} delay={at(0)} />
2. seed 公式只用 i / local，禁 Math.random
3. HUD 同屏时把透明度再降一档

```tsx
import { CodeRain } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<CodeRain local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 每帧乱跳
- 字符铺满正文区
- 与终端打字机叠在同一位置

## 7. 变化空间（同一效果的不同用法）

- 十六进制轨
- 二进制轨
- 日志流

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
