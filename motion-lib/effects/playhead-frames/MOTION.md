# Playhead Across Frames — 播放头扫画格 · Motion Prompt

> 时间线、画格和预览区放同一面板；播放头扫过画格→显示导出文件→缩略图逐个换成新素材并继续播放。
>
> 来源 `M15` ｜ 分类 **D · 操作演示** ｜ 组件 `PlayheadFrames` ｜ 建议时长 30~70 帧

## 1. 它是什么，不是什么

时间线、画格和预览区放同一面板；播放头扫过画格→显示导出文件→缩略图逐个换成新素材并继续播放。

**不是**：不是套模板前后轨道版式变了；版式变了就看不出是同一个模板。

## 2. 触发词与时机

- **触发词**：导出、套模板、下一张、批量
- **时序**：「导出」帧起播放头扫过 N 格（duration 默认 60）；缩略图逐个 pop 替换。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

轨道 + 画格 + 预览区三段式；已扫过的画格高亮。

## 4. 原生动作（菜单，按需取用）

- **播放头扫过＝播放／导出**｜适合：时间线工具、剪辑
- **画格高亮＝已处理**｜适合：批量操作
- **缩略图替换＝套模板**｜适合：素材批量换图

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <PlayheadFrames count={8} local={local} delay={at(2)} duration={60} />
2. 画格高亮用 i <= floor(p*count)
3. 套模板前后保持轨道与版式完全一致

```tsx
import { PlayheadFrames } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<PlayheadFrames count={8} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 轨道版式前后不一致
- 播放头跳格
- 导出结果与画格无关

## 7. 变化空间（同一效果的不同用法）

- 导出视频
- 套用模板
- 批量换图

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
