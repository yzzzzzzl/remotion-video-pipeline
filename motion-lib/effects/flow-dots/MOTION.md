# Flow Dots & Branch Highlight — 走线流动 + 支路高亮 · Motion Prompt

> 小块沿走线进入目标并高亮经过的节点；区分可选路径时只改变该支路的亮度，主线保持易读。
>
> 来源 `M09` ｜ 分类 **C · 过程演示** ｜ 组件 `FlowDots` ｜ 建议时长 24~40 帧

## 1. 它是什么，不是什么

小块沿走线进入目标并高亮经过的节点；区分可选路径时只改变该支路的亮度，主线保持易读。

**不是**：不是所有支路一起亮；一起亮就丢了分流语义。

## 2. 触发词与时机

- **触发词**：数据、传输、分流、并行
- **时序**：「传输」发声帧起，小块错峰 3 帧沿路移动 30 帧；当前支路 active=true，其余 false。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

两个清晰节点 + 细走线；小块 12px；未选中支路 opacity 0.28。

## 4. 原生动作（菜单，按需取用）

- **小块流动＝数据在走**｜适合：请求、数据、任务流
- **支路压暗＝未选中**｜适合：并行分流、可选路径
- **节点高亮＝到达**｜适合：处理完成的环节

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <FlowDots x1={80} y1={210} x2={820} y2={210} local={local} delay={at(2)} active={true} />
2. 常与 DrawPath 叠加：先画线再走块
3. 多个支路各用一个 FlowDots，只给当前支 active

```tsx
import { FlowDots } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<FlowDots x1={80} y1={210} x2={820} y2={210} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 所有支路同亮同动
- 小块穿过文字区
- 路径没有可见节点

## 7. 变化空间（同一效果的不同用法）

- 单线数据流
- 双路分流
- 三路汇聚

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
