# Context Before Value — 先口径后揭值 · Motion Prompt

> 先出日期，再出平台/对象，再出单位，最后才揭主数字；主数字用放大字号和识别色。
>
> 来源 `M16` ｜ 分类 **E · 数据揭示** ｜ 组件 `ContextThenValue` ｜ 建议时长 32~56 帧

## 1. 它是什么，不是什么

先出日期，再出平台/对象，再出单位，最后才揭主数字；主数字用放大字号和识别色。

**不是**：不是先亮大数字再补口径；那样观众会误读数据范围。

## 2. 触发词与时机

- **触发词**：数据显示、统计、根据报告、任何数字前
- **时序**：四段分别 at(n)+i*8 帧进场；主数字落地后停稳 ≥30 帧。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

口径三行小字（24px）+ 主数字（96px）；只表示这一个平台/口径，不扩写成全局结论。

## 4. 原生动作（菜单，按需取用）

- **先口径＝数据可信**｜适合：日期、平台、单位
- **后揭值＝ payoff**｜适合：核心统计数字
- **排名下一拍点亮**｜适合：榜单、对比数据

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ContextThenValue parts={['2026 Q3','平台 A','万次']} value='59.2' local={local} delay={at(2)} />
2. 数字用 fontVariantNumeric: tabular-nums 防跳动
3. 停稳期挂一个永动小元素满足铁律四

```tsx
import { ContextThenValue } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ContextThenValue parts={['2026 Q3','平台 A','万次']} value='59.2' local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 先亮数字再补口径
- 把单平台数据说成全网
- 数字没有单位

## 7. 变化空间（同一效果的不同用法）

- 下载量揭值
- 耗时揭值
- 排名揭值

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
