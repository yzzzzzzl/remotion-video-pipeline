# Image Relay — 多图接力换位 · Motion Prompt

> 多张原图沿横轴错峰滑入分别停住，重点那张停在画面中间；局部去掉空白边缘只留主体。
>
> 来源 `M20` ｜ 分类 **F · 对比合流** ｜ 组件 `ImageRelay` ｜ 建议时长 30~70 帧

## 1. 它是什么，不是什么

多张原图沿横轴错峰滑入分别停住，重点那张停在画面中间；局部去掉空白边缘只留主体。

**不是**：不是多图同时堆成一屏；那是元素进场与关键词上限的双重违规。

## 2. 触发词与时机

- **触发词**：这几张、划着看、多张图
- **时序**：每张 at(n+i*2)+12 帧滑入；重点张停留时长 > 其余。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

横轴排列，zIndex 递增；重点张 scale 1.08 居中。

## 4. 原生动作（菜单，按需取用）

- **错峰滑入＝逐张看**｜适合：图集、作品集
- **重点停中间＝当前主题**｜适合：讲解某一张
- **收进文件夹＝归档**｜适合：结尾汇总

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ImageRelay items={imgs} focusIndex={2} local={local} delay={at(1)} gap={8} />
2. 素材走 12 A/B 档并统一压色
3. 落位/切换可配短音 0.2~0.4

```tsx
import { ImageRelay } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ImageRelay items={[<div style={{width:200,height:140,background:"#123"}}>1</div>,<div style={{width:200,height:140,background:"#234"}}>2</div>]} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 多图同时堆一屏
- 图片留白边缘太多
- 重点张没有多停留

## 7. 变化空间（同一效果的不同用法）

- 作品集接力
- 截图接力
- 资料卡接力

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
