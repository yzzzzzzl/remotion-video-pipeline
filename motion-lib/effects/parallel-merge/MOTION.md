# Parallel Tracks Merge — 分路并行 + 结果合流 · Motion Prompt

> 同一任务分进 A、B 两条轨道分别推进并标记各自结果，结束时把选中的有效结果连到一张确认卡。
>
> 来源 `M18` ｜ 分类 **F · 对比合流** ｜ 组件 `ParallelMerge` ｜ 建议时长 40~80 帧

## 1. 它是什么，不是什么

同一任务分进 A、B 两条轨道分别推进并标记各自结果，结束时把选中的有效结果连到一张确认卡。

**不是**：不是两轨进度完全同步；同步就看不出是在比较。

## 2. 触发词与时机

- **触发词**：A/B、对比、两种方案、并行
- **时序**：分叉 at(n)、启动 at(n)+4、合流 at(n)+24；三个节点可配短提示音（0.2~0.4 音量）。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

两轨上下错位；确认卡在底部中央压住结果但不盖住两轨数值。

## 4. 原生动作（菜单，按需取用）

- **分叉＝两条路线**｜适合：A/B 测试、方案对比
- **各自推进＝差异显现**｜适合：速度、质量对比
- **合流＝结论**｜适合：选出有效方案

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ParallelMerge left={…} right={…} result={确认卡} local={local} delay={at(1)} mergeDelay={24} />
2. 两轨进度故意错开 4~8 帧
3. 确认卡出现后停稳 ≥1s

```tsx
import { ParallelMerge } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ParallelMerge left={<div>A 方案</div>} right={<div>B 方案</div>} result={<div>选择 B</div>} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 两轨完全同步
- 结论卡盖住两轨结果
- 没有标记各自结果

## 7. 变化空间（同一效果的不同用法）

- A/B 测试
- 新旧方案对比
- 两条路径对比

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
