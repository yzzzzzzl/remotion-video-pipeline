# Result Hold — 结果停稳 + 关键词分两拍 · Motion Prompt

> 操作讲完后画面停稳 ≥1 秒让人读完结果；收尾回开场构图，先亮第一拍（关键词/成果），再亮第二拍（领取/关注）。
>
> 来源 `M21` ｜ 分类 **G · 收尾** ｜ 组件 `ResultHold` ｜ 建议时长 40~90 帧

## 1. 它是什么，不是什么

操作讲完后画面停稳 ≥1 秒让人读完结果；收尾回开场构图，先亮第一拍（关键词/成果），再亮第二拍（领取/关注）。

**不是**：不是结果一闪就切走；也不能用「点赞关注」代替本片结论。

## 2. 触发词与时机

- **触发词**：结论、领取方式、关注、最后
- **时序**：结果层保持 >1s；两拍分别 at(n) 与 at(n)+24 帧进场；始终留字幕空间。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

回开场构图；两拍错开 24 帧；低对比度项目名可滚动带出。

## 4. 原生动作（菜单，按需取用）

- **停稳＝读完结果**｜适合：结论、最终数字
- **第一拍＝关键词/成果**｜适合：回扣开场问题
- **第二拍＝行动指令**｜适合：领取方式、名字

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ResultHold local={local} delay={at(5)} len={180}>结论</ResultHold>
2. 停稳期保留一个永动小元素避免铁律四违规
3. 结尾必须解决开场抛出的悬念

```tsx
import { ResultHold } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ResultHold local={local} delay={at(0)} len={180}><div style={{fontSize:80}}>结论：先定版再动画</div></ResultHold>
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 结果一闪就切走
- 用点赞关注代替结论
- 结尾与开场构图完全无关

## 7. 变化空间（同一效果的不同用法）

- 结论回扣
- 成果+领取
- 关键词+项目名

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
