# Two-Page Spread — 双页展开 / 版式对照 · Motion Prompt

> 先给一个案例卡，再并列放大两种排版保留尺寸与文字差异；或借纸面折合把封面与内页展开成对页。
>
> 来源 `M19` ｜ 分类 **F · 对比合流** ｜ 组件 `SpreadPages` ｜ 建议时长 20~40 帧

## 1. 它是什么，不是什么

先给一个案例卡，再并列放大两种排版保留尺寸与文字差异；或借纸面折合把封面与内页展开成对页。

**不是**：不是两种排版缩放不一致；不一致就无法公平对照。

## 2. 触发词与时机

- **触发词**：同一内容做两种、封面与内页、排版对比
- **时序**：两卡错峰 6 帧 pop 进场；折合用 rotateY(-18°→0)，落稳后保留对照阅读。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

两卡并排等宽等高；文字差异处用识别色圈出。

## 4. 原生动作（菜单，按需取用）

- **对页展开＝对照阅读**｜适合：封面/内页、纸质/数字
- **错峰立起＝先左后右**｜适合：两种版式依次介绍
- **差异圈出＝重点**｜适合：字号、留白差异

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <SpreadPages left={…} right={…} local={local} delay={at(2)} gap={6} />
2. 两卡必须同宽同高
3. 真实排版素材走 12 A 档

```tsx
import { SpreadPages } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<SpreadPages left={<div style={{border:"1px solid #6FE3D2",padding:40}}>封面</div>} right={<div style={{border:"1px solid #6FE3D2",padding:40}}>内页</div>} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 两卡缩放不一致
- 差异处没有标记
- 展开后立刻切走

## 7. 变化空间（同一效果的不同用法）

- 封面/内页对页
- 两种排版并列
- 纸质/数字对照

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
