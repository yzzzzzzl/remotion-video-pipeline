# Slow Push / Flip / Gild — 缓推近 / 书页翻动 / 烫金浮出 · Motion Prompt

> 三种慢速质感：缓推近 1.0→1.06、书页翻动 rotateY(-22°→0)、烫金光带遮罩浮出。
>
> 来源 `10 §4` ｜ 分类 **H · 开场装饰** ｜ 组件 `SlowPush` ｜ 建议时长 60~120 帧

## 1. 它是什么，不是什么

三种慢速质感：缓推近 1.0→1.06、书页翻动 rotateY(-22°→0)、烫金光带遮罩浮出。

**不是**：不是科技 HUD 那套快切；人文历史主题要慢、少元素、留白多。

## 2. 触发词与时机

- **触发词**：书籍、人文、历史
- **时序**：触发后 90 帧缓慢完成；期间保持一个微动元素避免静止。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

主体图/文字占中；背景留白；装饰 ≤2 个。

## 4. 原生动作（菜单，按需取用）

- **缓推近＝注视**｜适合：书籍、画作
- **翻页＝章节转换**｜适合：历史、人文
- **烫金浮出＝质感**｜适合：古籍、档案

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <SlowPush mode="gild" local={local} delay={at(0)}>标题</SlowPush>
2. mode 三选一：push / flip / gild
3. 全片沿用同一套 token，不只开场

```tsx
import { SlowPush } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<SlowPush mode="gild" local={local} delay={at(0)}><div style={{fontSize:80}}>历史与人</div></SlowPush>
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 人文主题套科技代码雨
- 慢动作里画面全静止
- 元素堆太多

## 7. 变化空间（同一效果的不同用法）

- 书页翻动
- 烫金浮出
- 缓推近

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
