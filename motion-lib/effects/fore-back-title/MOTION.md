# Fore/Back Title Block — 前后景大字遮挡 · Motion Prompt

> 主标题分前后两层：后景大字铺主体区，前景元素晚 4 帧压住下缘约 1/4，读出「字在物后面」的层次。
>
> 来源 `M01` ｜ 分类 **A · 开场钩子** ｜ 组件 `ForeBackTitle` ｜ 建议时长 16~28 帧

## 1. 它是什么，不是什么

主标题分前后两层：后景大字铺主体区，前景元素晚 4 帧压住下缘约 1/4，读出「字在物后面」的层次。

**不是**：不是普通标题淡入；前景绝不能盖住关键字，也不能和后景同时进场。

## 2. 触发词与时机

- **触发词**：主题词、数字首次出现、章节揭题
- **时序**：主题词发声帧触发后景从两侧揭开；+4 帧前景 pop 压角；揭开完成停稳 ≥1s。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

后景 110~140px 粗体；前景用 Card / 声波头像 / 工具 logo 覆盖下缘一小条；整屏文字块 ≤3。

## 4. 原生动作（菜单，按需取用）

- **后景揭开＝主题登场**｜适合：新概念、章节揭题、反常识断言
- **前景压角＝空间层次**｜适合：工具名、资料卡、真人素材
- **揭开后微推近＝定调**｜适合：开场首帧

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ForeBackTitle back={主题词} front={<Card>…</Card>} local={local} delay={at(0)} />
2. frontDelay 默认 4；揭开幅度由 prog 驱动 clipPath inset
3. 无真人素材时用 Card 或 logo，不做抠像

```tsx
import { ForeBackTitle } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ForeBackTitle back={"让画面动起来"} front={<div style={{border:"1px solid #6FE3D2",padding:12}}>TOOL</div>} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 前景压住关键字读不出全文
- 字全露＝没有层次，白做
- 前景与后景同帧进场

## 7. 变化空间（同一效果的不同用法）

- 前景换成用户真人素材压角
- 后景换成结论数字
- 前景用工具 logo 压住下缘 1/5

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
