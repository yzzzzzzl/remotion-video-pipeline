# Checklist Into Trend — 逐条打勾 + 趋势逐点 · Motion Prompt

> 一张连续记录界面：提到计划时逐条列出项目，讲到完成时按组亮起勾选；到成效段复用前面的数据把趋势线逐点画出。
>
> 来源 `M17` ｜ 分类 **E · 数据揭示** ｜ 组件 `ChecklistTrend` ｜ 建议时长 40~80 帧

## 1. 它是什么，不是什么

一张连续记录界面：提到计划时逐条列出项目，讲到完成时按组亮起勾选；到成效段复用前面的数据把趋势线逐点画出。

**不是**：不是趋势线用前面没出现过的新数字；观众无法验证。

## 2. 触发词与时机

- **触发词**：计划→完成→成效、逐条、趋势、累计
- **时序**：勾选用 local >= at(n+i) 切换；趋势 strokeDashoffset 逐点，在最后一条勾完后 24 帧画完。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

清单区 + 趋势区上下排布；趋势标注复用清单数值。

## 4. 原生动作（菜单，按需取用）

- **逐条打勾＝完成感**｜适合：计划、任务、清单
- **趋势逐点＝累积结果**｜适合：成效、增长
- **复用数据＝可验证**｜适合：前后呼应的数据片

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <ChecklistTrend items={[…]} trendPath='M 0 180 L 180 140 …' local={local} delay={at(1)} />
2. 演示数据标注「示意」
3. 勾选与趋势共用一套识别色

```tsx
import { ChecklistTrend } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<ChecklistTrend items={['计划','完成','成效']} trendPath='M 0 180 L 180 140 L 360 60' local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 趋势用新数据
- 勾选同时全亮
- 清单与趋势分成两页失去连续性

## 7. 变化空间（同一效果的不同用法）

- 任务完成清单
- 成效趋势
- 打卡记录

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
