# Equalizer Bars — 均衡器 / 柱状生长 · Motion Prompt

> 26 + abs(sin(local*0.28 + i*0.85))*96 驱动的柱状条，永不静止且完全确定性。
>
> 来源 `10 §4` ｜ 分类 **H · 开场装饰** ｜ 组件 `EqualizerBars` ｜ 建议时长 30~120 帧

## 1. 它是什么，不是什么

26 + abs(sin(local*0.28 + i*0.85))*96 驱动的柱状条，永不静止且完全确定性。

**不是**：不是随机跳动；相位差必须由 index 决定。

## 2. 触发词与时机

- **触发词**：数据、音频、增长
- **时序**：触发后常驻到章节末，配合口播节奏衰减运动密度。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

底部或侧边一排细柱；不压字幕条。

## 4. 原生动作（菜单，按需取用）

- **柱状起伏＝活跃**｜适合：音频、增长
- **相位差＝自然感**｜适合：避免整齐划一
- **低透明度＝退到背景**｜适合：不抢主体

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <EqualizerBars count={26} local={local} delay={at(0)} />
2. 公式里的 i 是柱序号，保证相位差
3. 放在字幕条上方空隙

```tsx
import { EqualizerBars } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<EqualizerBars local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 柱子压到字幕
- 所有柱同步动
- 颜色太亮抢主体

## 7. 变化空间（同一效果的不同用法）

- 底部均衡器
- 侧边柱状
- 增长柱状图

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
