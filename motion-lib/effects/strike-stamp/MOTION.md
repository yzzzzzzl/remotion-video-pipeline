# Strike & Stamp — 删除线 + 印章 · Motion Prompt

> 一条随 t 增长的删除线盖在错误说法上，末尾配一个旋转方框印章（FALSE），不用圆。
>
> 来源 `10 §4` ｜ 分类 **H · 开场装饰** ｜ 组件 `StrikeStamp` ｜ 建议时长 16~28 帧

## 1. 它是什么，不是什么

一条随 t 增长的删除线盖在错误说法上，末尾配一个旋转方框印章（FALSE），不用圆。

**不是**：不是红色方标点缀；印章必须是方框，且不能盖住正确说法。

## 2. 触发词与时机

- **触发词**：破除误区、其实不是、错误做法
- **时序**：「其实不是」发声帧起划掉 16 帧；印章 8 帧后压上。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

错误说法居中；印章在右上角旋转 -9°；正确说法下一拍进场。

## 4. 原生动作（菜单，按需取用）

- **划掉＝否定**｜适合：误区、错误做法
- **盖章＝结论确认**｜适合：破误区
- **下一拍亮正确说法＝对比**｜适合：纠正

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <StrikeStamp local={local} delay={at(1)} stamp="FALSE">错误说法</StrikeStamp>
2. 删除线 width = p*112%
3. 印章用方框，不用圆

```tsx
import { StrikeStamp } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<StrikeStamp local={local} delay={at(0)} stamp="FALSE" style={{fontSize:64}}>错误说法</StrikeStamp>
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 用圆印章
- 印章盖住正确说法
- 划掉线不随帧增长

## 7. 变化空间（同一效果的不同用法）

- 划掉误区
- 盖章否定
- 先划后立

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
