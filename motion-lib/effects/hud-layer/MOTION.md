# Persistent HUD Layer — 常驻 HUD 层 · Motion Prompt

> REC 状态、解码帧号、四角 L 框、扫描线组成的常驻装饰层，透明度 0.3~0.6。
>
> 来源 `10 §4` ｜ 分类 **H · 开场装饰** ｜ 组件 `HUDLayer` ｜ 建议时长 0~450 帧

## 1. 它是什么，不是什么

REC 状态、解码帧号、四角 L 框、扫描线组成的常驻装饰层，透明度 0.3~0.6。

**不是**：不是画大圆圈当装饰；只用 L 角标、方括号、终端框。HUD 只在第 0 章，450 帧后必须完全消失。

## 2. 触发词与时机

- **触发词**：技术、系统感、开场
- **时序**：frame 0 进场；章末（默认 frame 450）卸载，切章后抽 1 帧逐项确认无残留。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

四角 L 框 + 左上 REC + 右下帧号 + 横扫线；装饰行放在字幕条上方。

## 4. 原生动作（菜单，按需取用）

- **四角框＝画框感**｜适合：系统界面
- **帧号＝实时感**｜适合：技术主题
- **扫线＝一直活着**｜适合：防止静止

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <HUDLayer local={local} delay={at(0)} label="REC" />
2. opacity 0.3~0.6，pointerEvents:none
3. 装饰文字计入一屏 ≤5 个文字元素

```tsx
import { HUDLayer } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<HUDLayer local={local} delay={at(0)} label="REC" />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 450 帧后残留
- HUD 压住字幕/头像/帧计数器
- 透明度过高抢主体

## 7. 变化空间（同一效果的不同用法）

- 科技 HUD
- 雷达 HUD
- 极简角标

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
