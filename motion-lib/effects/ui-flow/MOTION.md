# UI Step Flow — 界面流程演示 · Motion Prompt

> 一个桌面窗口演示完整流程，窗口位置全程不跳；下拉选中→进度条→焦点切换→问答按台词锚点逐段揭示。
>
> 来源 `M13` ｜ 分类 **D · 操作演示** ｜ 组件 `UIFlow` ｜ 建议时长 40~90 帧

## 1. 它是什么，不是什么

一个桌面窗口演示完整流程，窗口位置全程不跳；下拉选中→进度条→焦点切换→问答按台词锚点逐段揭示。

**不是**：不是每步都换窗口位置；位置跳了观众就丢失上下文。

## 2. 触发词与时机

- **触发词**：选择、安装、开始用、配置
- **时序**：每一步由 delays[i]=at(i) 触发，用 popStyle 逐段进场；进度条宽度随 local 增长。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

单窗口 Card 固定位置；内部最多 4 个步骤块；次要选项在继续讲配置时折叠。

## 4. 原生动作（菜单，按需取用）

- **下拉选中＝用户操作**｜适合：选项、配置
- **进度条填充＝等待**｜适合：安装、生成
- **焦点切换＝下一步**｜适合：提问与回答

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <UIFlow steps={[下拉, 进度条, 输入框, 问答]} delays={[at(0),at(1),at(2),at(3)]} local={local} />
2. 真实界面截图/录屏按 12 取，否则代码画 mockup
3. 窗口位置用固定 left/top，不随步骤变

```tsx
import { UIFlow } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<UIFlow steps={[<div>选择模板</div>,<div>进度 100%</div>,<div>输入问题</div>]} delays={[at(0),at(1),at(2)]} local={local} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 窗口每步都变位置
- 一次揭示全部步骤
- 进度条与口播不同步

## 7. 变化空间（同一效果的不同用法）

- 安装流程
- 配置流程
- 提问对话流程

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
