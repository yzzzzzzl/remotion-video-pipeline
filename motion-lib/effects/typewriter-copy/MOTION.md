# Typewriter & Copy — 打字机 + 复制粘贴 · Motion Prompt

> 便笺和输入框共用同一底色；按口播节奏逐字输入，输入完把整张内容做成浅色副本滑出，再滑入新输入框。
>
> 来源 `M14` ｜ 分类 **D · 操作演示** ｜ 组件 `TypewriterCopy` ｜ 建议时长 30~70 帧

## 1. 它是什么，不是什么

便笺和输入框共用同一底色；按口播节奏逐字输入，输入完把整张内容做成浅色副本滑出，再滑入新输入框。

**不是**：不是三行一次出现；也不能换场景就换一张便笺。

## 2. 触发词与时机

- **触发词**：写三行、复制、粘贴、prompt
- **时序**：每行起点对齐该行发声帧；复制副本在打完后 +6 帧滑出，14 帧停稳。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

同一张便笺贯穿始终；光标 sin 闪烁；副本与原稿视觉上明显区分。

## 4. 原生动作（菜单，按需取用）

- **逐字输入＝正在写**｜适合：prompt、代码、命令行
- **副本滑出＝复制**｜适合：复用内容、模板
- **副本滑入＝粘贴**｜适合：换地方继续用

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <TypewriterCopy text="节奏要快，字幕放大" local={local} delay={at(4)} />
2. perChar=3；中文按字符计
3. 落位卡重音可叠加 number-accent

```tsx
import { TypewriterCopy } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<TypewriterCopy text="先定版，再上动效" local={local} delay={at(0)} style={{fontSize:48}} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 三行一次出现
- 换场景换了便笺
- 光标常亮不闪

## 7. 变化空间（同一效果的不同用法）

- 写 prompt
- 写代码
- 写清单

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
