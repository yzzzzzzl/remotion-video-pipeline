# Progressive Path Drawing — 逐段连线 / 手绘箭头 · Motion Prompt

> 从第一个节点出发，口播讲到下一段时逐段把线连出去，每段线旁紧跟一个 ≤8 字标注。
>
> 来源 `M10` ｜ 分类 **C · 过程演示** ｜ 组件 `DrawPath` ｜ 建议时长 30~70 帧

## 1. 它是什么，不是什么

从第一个节点出发，口播讲到下一段时逐段把线连出去，每段线旁紧跟一个 ≤8 字标注。

**不是**：不是一次性画完整张关系图；观众跟不上也说不清现在讲哪段。

## 2. 触发词与时机

- **触发词**：流程、关系、连起来、从 A 到 B
- **时序**：每段由 at(n+i) 触发，12 帧画完；节点在段起点 +2 帧 pop。
- `delay` 必须来自 `at(i)`（本章台词行索引 → 本页帧偏移，见 `../../../references/03-audio-timeline.md`），**禁止写死秒数或常数帧**。
- 局部帧 `t = local - delay`；`t < 0` 时必须保持未触发的初始态。

## 3. 画面构成

底层是示意图或代码 mockup；SVG path 用 pathLength=1 归一化，免算线长。

## 4. 原生动作（菜单，按需取用）

- **逐段画出＝讲解推进**｜适合：流程、链路、关系图
- **线头展开＝下一段预告**｜适合：章节衔接
- **节点点亮＝当前位置**｜适合：多步骤说明

每章挑 **1 个主动作用透**，比每页换花活更强；装饰特效只补运动密度。

## 5. 实现配方

1. <DrawPath paths={['M 80 200 L 300 200', 'M 300 200 L 520 120']} local={local} delay={at(2)} gap={10} />
2. 每段配一个短标注，跟着段起点进场
3. 真实流程图按 12 A/B 档取素材

```tsx
import { DrawPath } from "./MotionKit";
// local = 本页内帧号；delay = at(i)
<DrawPath paths={['M 80 200 L 320 200', 'M 320 200 L 620 120']} local={local} delay={at(0)} />
```

`core/MotionKit.tsx` 是全部效果的唯一代码源：拷进 `remotion-project/src/components/` 即可，**不引入新 npm 依赖**。

## 6. 反模式 / 坑

- 一次性画完整张图
- 标注字数超 8 字
- 线穿过字幕安全区

## 7. 变化空间（同一效果的不同用法）

- 手绘箭头流程
- 拓扑关系图
- 断线＝失败路径

## 8. 质检（三帧抽查）

- 动作起点**前 1 帧**：元素尚未出现。
- 起点**后 2 帧**：正在进场。
- **结果停稳帧**：可读、无重叠、无溢出；停稳期保留一个永动小元素（铁律四）。
- 一屏文字块 ≤3~4，完整句子只进字幕条；`Math.random()` 一律禁用。
- 装饰类效果（H 组）额外确认：**frame 450 后无任何 HUD 残留**。
