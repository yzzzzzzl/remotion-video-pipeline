# 交付说明 · 画风库 style-lib（60 个画风）

> 2026-11-28 用户诉求：「我希望我的 skill 出产的视频是多画风，3-5 个太少了，起码 50 个画风」。
> 交付：**60 个原创画风 / 12 类**，比下限多 20%，并且**真的能在 Remotion 里渲染出不同画面**，不只是文字提示词。

## 一句话结论

skill 现在有两层正交能力：

| 层 | 目录 | 数量 | 管什么 | 代码源 |
|---|---|---|---|---|
| 画风层（本次新增） | `style-lib/` | **60 个 / 12 类** | 整片色板、字体、底板、材质、镜头气质 | `core/StyleKit.tsx` |
| 动作层（v1.8 已有） | `motion-lib/` | 31 个 / 8 组 | 元素怎么动、跟台词 `at(i)` 触发 | `core/MotionKit.tsx` |

一支片 = **1 个画风 slug + 每章 1 个主动作**。取色用 `getStyle(slug).palette.accent` 传给动效组件，**不改 MotionKit 源码**。

## 与 lemo-opuscar 的关系（重要）

只借鉴它的**组织方式**（通用入口 → 逐卡规则 → 索引 → 技术与导演指南 → 自定义目录 → 各 Agent 适配入口）和「风格库」这个层次概念。

- **未复制**它的 99 张 `STYLE.md` 文本、任何 demo 成片代码、`core/` 的 Python / Three.js / Playwright / TTS / 音乐 / 素材管线、`LICENSES` 合规体系。
- 60 个画风的色板、材质、镜头、不变量、坑**全部原创**，面向「口播讲解视频」而不是电影风格复刻。
- 技术栈保持 React + Remotion + 原生 CSS，**零新增 npm 依赖**；不需要它那套 ~350MB 起的 Python 环境与图片生成器，4 核 Windows 直接跑。
- 它 README 明写「Claude 专用」；本库仍做成全 Agent 通用。

## 怎么用

给 Agent 的一句话（可复制）：

```text
请从 https://github.com/yzzzzzzl/remotion-video-pipeline 下载/克隆这个仓库，先读 style-lib/AGENTS.md 和 style-lib/styles/INDEX.md，按主题选 1 个画风（一整支片只用这一个），再读 motion-lib/INDEX.md 挑动作。用 StyleStage 包住整片，取色传给动效组件，delay 一律 at(i)；不新增 npm 依赖，做完抽三帧自检。
```

落地代码：

```tsx
const SLUG = "blueprint";              // 整片唯一
const t = getStyle(SLUG);

<StyleStage slug={SLUG}>
  <StyleCard slug={SLUG}>
    <NumberAccent local={local} delay={at(2)} color={t.palette.accent} />
  </StyleCard>
  <StyledCaption slug={SLUG}>{完整句子}</StyledCaption>
</StyleStage>
```

## 改哪里 → 重跑什么

| 想改 | 改 | 重跑 |
|---|---|---|
| 某个画风的色板/字体/规则 | `scripts/styles.json` 对应对象 | `build_styles.py` → `validate_styles.py` → 抽帧 |
| 加一个新画风 | `styles.json` 的 `styles` 数组加一项（或 `~/remotion-my-styles/<slug>/`） | 同上；索引自动更新 |
| 底板渲染逻辑 | `core/StyleKit.tsx` | esbuild 编译 → `remotion still` 三帧目检 |
| 只换某一支片的画风 | 工程里那个 `SLUG` 常量 | 重渲该片即可，页面/动效/时间轴都不用动 |

## 常见误区（已写进文档）

- 「多画风」= skill 能产出 60 种不同片子，**不是一支片里混 60 种**；一支片只用 1 个 slug。
- 不要每页换皮、不要开场用 A 正片用 B；开场与正片必须同画风。
- 画风不接管动作时序，`delay` 仍一律 `at(i)`。
- 不要为画风装外部字体/图片/Three.js。
