## 1. 它是什么，不是什么

写清楚这套画风统一了什么（色板/字体/材质/镜头），以及它**不规定具体动作**（动作由 motion-lib 提供）。

## 2. 色板

| 用途 | 色值 |
|---|---|
| 背景 bg | `#000000` |
| 面板 surface | `#000000` |
| 主文字 text | `#000000` |
| 主强调 accent | `#000000` |
| 次强调 accent2 | `#000000` |

主强调色全片只服务最重要的元素。

## 3. 字体与排版

标题 / 正文 / 数字标注分别用什么系统字体栈、字重、字距。**不加载外部字体文件**。

## 4. 底板与材质

`stage.type` 取 `grid / scanlines / paper / chalk / stroke / flat / glow / film / dots / toy / lens / lines` 之一；写清材质、网格模数、辉光、暗角。

## 5. 动作质感

观感、缓动、入场方式、运动密度（低/中/高）、基准 30fps。画风只定质感，不接管 `at(i)`。

## 6. 镜头语法

一句话：锁死 / 缓慢推近 / 等距平移 / 硬切 …

## 7. 适用 / 不适用 / 触发词

- **适合**：至少 2 项
- **不适合**：至少 2 项（比「适合」更重要）
- **触发词**：至少 3 个

## 8. 不变量（不可协商）

至少 2 条，例如「只用一个强调色」「所有线条等粗」「构图左右对称」。

## 9. 反模式 / 坑

至少 2 条。

## 10. 与动效库组合

`StyleStage` 包整片 → `getStyle(slug).palette.accent` 传给 `MotionKit` 组件 → `delay` 仍 `at(i)` → 一整支片 1 个 slug。

## 11. 质检（三帧抽查）

起点前 1 帧 / 起点后 2 帧 / 结果停稳帧；另查全片只有一个 slug、字幕条可读。
